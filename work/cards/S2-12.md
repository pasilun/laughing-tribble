Do: `edit`, the one tool that changes a document's content. It does what `plan_edit` does (read `plan_edit` in `lib/plan/mcp/tools-edit.ts`), with the contract's answer and findings. Do not change `plan_edit`.

`lib/plan/connector/handlers/edit.ts`: `export async function edit(args: Args): Promise<ToolResult>`. Every return is `toToolResult(answer(…), { summary, images? })`; a failure is `ok: false` with `findings` and the summary `Ingen ändring sparades: ` + the first finding's message.

Steps, in order:
1. **Arguments.** `id` must be a non-empty string, `base_revision` an integer, `ops` an array of objects each with a string `op`, `dry_run` and `image` booleans when given, `message` a string when given. Otherwise `badArgument(name, why)` (why e.g. `krävs` or `ska vara ett heltal`), stop at the first.
2. **Names.** For each op i, `OPERATIONS.resolve(op.op)`. Collect the findings of unknown names (add `index: i` to each finding's `data`); if there are any, answer them all and stop. Nothing has been read or saved.
3. **Load.** `loadPlan(id)` (from `../../service`); `null` is `notFound(id)`.
4. **Stale.** When `base_revision !== loaded.meta.n`: `staleRevision(base_revision, loaded.meta.n)`, with `next: [{ tool: 'get', arguments: { id, since: base_revision }, why: 'Läs vad som ändrats och gör om ändringen' }]`.
5. **Dry run.** When `dry_run === true`: `applyOps(loaded.plan, ops)` (from `../../domain/ops`). `errors` non-empty: one `invalidOperation(message)` per error. Otherwise answer `ok: true`, `id`, `revision: loaded.meta.n`, `changed: changedList(before, after)`, `findings` = `freshFindings(checkPlan(before), checkPlan(after)).fresh`, `data: { dry_run: true }`, summary `Provkörning: inget sparades. Revision ${n} är kvar.`
6. **Save.** `editPlan(id, ops, base_revision, 'claude', message ?? 'Ändring av Claude')`. Status 404 is `notFound`; 409 is `staleRevision(base_revision, res.head)`; any other non-200 is one `invalidOperation(message)` per error. On 200: `ok: true`, `id`, `revision: res.revision.n`, `changed: changedList(before, res.plan)`, `findings: fresh` from `freshFindings(checkPlan(before), checkPlan(res.plan))`, `next`: when `fresh` has any finding of level `error` or `warning`, `[{ tool: 'check', arguments: { id }, why: 'Se vad som återstår' }]`, otherwise none. Summary: `Sparad som revision ${n}.` plus ` ${gone} anmärkningar är åtgärdade.` when `gone > 0`.
7. **Picture.** When `image === true` and the edit was saved (not a dry run), append `await preview(res.plan, 'efter', false)` from `../../mcp/format` to `images`.

Then in `lib/plan/connector/handlers/index.ts` replace the `edit` entry with this handler. Change nothing else there.

Tests (`e2e/connector-edit.spec.ts`, API tests; `makePlan`, `connector`, `legacy` from `e2e/connector-helpers.ts`; the demo plan has an opening `ny-oppning`):
- **saves:** `edit { id, base_revision: 1, ops: [update opening ny-oppning width 1000], message: 'Bredare' }` → `structuredContent` has `ok: true`, `contract: 1`, `revision: 2`, `changed` containing `{ kind: 'opening', id: 'ny-oppning', what: <string containing 'ändrad'> }`; `isError` falsy; one content block only; the old `plan_get { plan_id }` text says `Revision 2`.
- **stale:** the same call again (`base_revision: 1`) → `ok: false`, `findings[0].code === 'stale-revision'`, `findings[0].data.current === 2`, `next[0].tool === 'get'`, `isError === true`.
- **unknown name:** `ops: [{ op: 'moveWal', id: 'a-hall', dx: 0, dy: 10 }]` with `base_revision: 2` → `ok: false`, `findings[0].code === 'unknown-name'`, `findings[0].data.nearest === 'moveWall'`, `findings[0].data.index === 0`; the plan is still at revision 2 (`plan_get`).
- **dry run:** `dry_run: true` with a valid `moveWall` → `ok: true`, `revision: 2`, `data.dry_run === true`, `changed` not empty; `plan_get` still says revision 2.
- **invalid:** `ops: [{ op: 'setWallLength', id: 'no-such-wall', length: 1000 }]` → `ok: false`, `findings[0].code === 'invalid-operation'`.
- **unknown plan:** `id: 'no-such-plan'` → `findings[0].code === 'not-found'`.
- **bad argument:** `base_revision: 'x'` → `findings[0].code === 'bad-argument'`.
- **picture:** `image: true` on a valid edit gives a second content block of type `image`.
