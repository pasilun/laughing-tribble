Do: make the tool list impossible to change by accident.

1. `scripts/freeze-connector.ts`:
```ts
// Writes e2e/fixtures/connector-tools.json from the tool definitions. Run it only on purpose: a change to this file is
// a change to the connector contract (docs/mcp-contract.md §7) and needs the maintainer's decision.
import { writeFileSync } from 'fs'
import { connectorTools } from '../lib/plan/connector/tools'

writeFileSync('e2e/fixtures/connector-tools.json', JSON.stringify(connectorTools(), null, 2) + '\n')
console.log('wrote e2e/fixtures/connector-tools.json')
```
2. `package.json`: add the script `"freeze:connector": "tsx scripts/freeze-connector.ts"` after `"eval:agent"` (add a comma to the line before). Change nothing else in `package.json`, and do not touch `package-lock.json`.
3. Run `npm run freeze:connector` once and keep the file it writes.
4. `e2e/connector-frozen.spec.ts` (pure):
   - read `e2e/fixtures/connector-tools.json` with `readFileSync` and `JSON.parse`; `expect(connectorTools()).toEqual(frozen)`; if it fails the message must say what to do: wrap in `expect(…, 'The connector tool list changed. Read docs/mcp-contract.md §7 before running npm run freeze:connector.')`;
   - the names equal `['guide', 'list', 'get', 'check', 'view', 'scan', 'edit', 'source', 'manage', 'export']`;
   - every description starts with `Planstudio:` and is at most 600 characters;
   - every `inputSchema` has `type: 'object'`; every tool has all three annotation hints as booleans;
   - the read-only tools (guide, list, get, check, view, scan) have `readOnlyHint: true`; edit, source, manage and export have `readOnlyHint: false`; only manage has `destructiveHint: true`;
   - `id` is in the `required` list of every tool except `guide`, `list` and `manage`;
   - no `inputSchema` mentions an operation name: `JSON.stringify(connectorTools())` does not contain `moveVertex` or `setWallLength` (contract §1: the vocabulary is the engine's).

Done when: `npm run typecheck && npm run lint && CI=1 npx playwright test e2e/connector-frozen.spec.ts --reporter=line 2>&1 | tail -40` passes.
