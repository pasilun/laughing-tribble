Do: the one function that packs an `Answer` for MCP. The text block must hold everything Claude needs (clients differ in whether they read `structuredContent`); `structuredContent` repeats the answer for programs.

`lib/plan/connector/result.ts`:
```ts
import type { Answer } from './types'

export type ImageBlock = { type: 'image'; data: string; mimeType: string }
export type ToolResult = {
  content: Array<{ type: 'text'; text: string } | ImageBlock>
  isError?: boolean
  structuredContent?: Answer
}

export function toToolResult(a: Answer, opts: { summary: string; images?: ImageBlock[] }): ToolResult
```
Behaviour:
1. The first content block is a text block made of these parts joined by a blank line, each part only when it has content:
   - `opts.summary`;
   - `Ändrat:` followed by one line `- {kind} {id}: {what}` per entry of `a.changed`;
   - `Anmärkningar:` followed by one line `- [{level}] {message}` per finding (add ` ({id})` when the finding has refs);
   - `Nästa:` followed by one line `- {tool} {JSON.stringify(arguments)} – {why}` per entry of `a.next`.
2. Then the images of `opts.images`, in order.
3. `isError: true` only when `a.ok` is false; the key is left out otherwise.
4. `structuredContent` is `a`, unchanged.

Tests (`e2e/connector-result.spec.ts`, pure): build an answer with `answer()` from `lib/plan/connector/answer`:
- with `changed: [{ kind: 'wall', id: 'v1', what: 'ändrad' }]`, one finding `{ level: 'warning', message: 'M', refs: ['v1'] }` (id `w:v1`), `next: [{ tool: 'check', arguments: { id: 'p' }, why: 'Se vad som återstår' }]` and summary `'Sparad.'` the text is exactly the following (`\n` stands for a newline):
  `Sparad.\n\nÄndrat:\n- wall v1: ändrad\n\nAnmärkningar:\n- [warning] M (w:v1)\n\nNästa:\n- check {"id":"p"} – Se vad som återstår`
  (build the finding with `finding({ id: 'w:v1', code: 'w', level: 'warning', message: 'M', refs: ['v1'] })`);
- an answer with `ok: true` and no lists gives one text block equal to the summary, no `isError` key, and `structuredContent` equal to the answer;
- `ok: false` gives `isError === true`;
- two images are appended after the text block in order.
