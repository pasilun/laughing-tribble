Defect (checkpoint S2-R2, reviewer): the handlers dispatch on literal names: `manage.ts` around lines 116-162 is an if-chain whose fall-through (`// trash`) runs `trash` for any new action; `view.ts` around lines 56, 80, 82 (`'sheet'`, `'overlay'`); `export.ts` around lines 206-210 (`'link'`, `'pdf'`). The S2-R1-f5 pattern put the behaviour in each registry entry.

Blocked: a refactor of three handlers and their registries, with a design choice (each entry carries its own `run`, as `CheckEntry` does) and the test surface to keep. Needs a card written with that design; set ready with attempts 0 after.
Also decide, in the same card: the sheet names `efter`/`fore`/`both` (reviewer: `view.ts` around line 18 and `export.ts` around line 181) belong in a `sheets` registry in `registries/`, and the reviewer notes they are not in `FAMILIES`, which the guide's vocabulary does not list (contract §8(2)). Adding a family changes the frozen families list checked by `e2e/connector-registries.spec.ts`, which needs an authorisation.

## Decided and rewritten 2026-11-11 by the spec author (committed to the repo)
Decision (replaces the earlier text; the larger refactor, each registry entry carrying its own `run`, is deferred and noted in `docs/mcp-contract.md` §11): keep the handlers' dispatch, but (a) an action, view or format that has a registry entry and no code answers `not-implemented` instead of falling through to another one, (b) the sheet names get their own registry family, and (c) a test calls every registered name so that a name without code fails the build.

1. `lib/plan/connector/registries/index.ts`: add after the `EXPORTS` registry
```ts
export const SHEETS = new Registry<Entry>('sheets', 'blad', [
  { name: 'efter', summary: 'The sheet with changes (default)' },
  { name: 'fore', summary: 'The sheet as it is today' },
  { name: 'both', summary: 'Före and efter together (export only)' },
])
```
   and in `FAMILIES` add `sheets: SHEETS,` right after `exports: EXPORTS,`.
2. `lib/plan/connector/handlers/view.ts`: delete the line that starts `const SHEETS = new Registry<Entry>('sheets'`, import `SHEETS` with the other import from `'../registries'` (`import { SHEETS, VIEWS } from '../registries'`), delete imports that become unused (`Registry`, `Entry` from `'../names'` if nothing else uses them), and after the line `  if ('finding' in sheet) return fail([sheet.finding])` add
