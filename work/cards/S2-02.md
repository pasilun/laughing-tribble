Do: a small registry for the engine's vocabulary (operations, views, actions …) and the finding that teaches a session the valid names.

`lib/plan/connector/names.ts`:
```ts
import { finding } from './answer'
import type { Finding } from './types'

export type Entry = { name: string; aliases?: string[]; summary: string }

export class Registry<E extends Entry> {
  // family: English key used in `data.kind` ('operations'); noun: Swedish word for messages ('operation').
  constructor(readonly family: string, readonly noun: string, readonly entries: E[]) {
    // throw new Error(`dubbelt namn ${n} i ${family}`) when a name or alias occurs twice
  }
  names(): string[]                       // canonical names, in declaration order
  get(name: string): E | undefined        // by canonical name or alias, exact match
  resolve(name: string): { entry: E } | { finding: Finding }   // unknown: { finding: unknownName(this, name) }
}

// The valid name closest to `name`, or undefined. Rules, in order:
// 1. a candidate that starts with `name` (when `name` has at least 2 characters), if exactly one does;
// 2. the candidate with the smallest Levenshtein distance, if that distance is <= max(2, floor(name.length / 3));
//    on a tie the earlier candidate wins.
export function nearest(name: string, candidates: string[]): string | undefined

// code 'unknown-name', level 'error', id `unknown-name:${family}:${name}`,
// message `Okänd ${noun} "${name}".${nearest ? ` Menade du "${nearest}"?` : ''} Giltiga: ${names.join(', ')}.`,
// data { kind: family, name, valid: names, nearest } (nearest left out when there is none)
export function unknownName(reg: Registry<Entry>, name: string): Finding
```
Write `levenshtein(a, b)` as a private function (standard two-row dynamic programme; no dependency).

Tests (`e2e/connector-names.spec.ts`, pure):
- registry `new Registry('operations', 'operation', [{ name: 'moveWall', aliases: ['flytta'], summary: 'x' }, { name: 'moveVertex', summary: 'y' }, { name: 'scale', summary: 'z' }])`:
  - `names()` is `['moveWall', 'moveVertex', 'scale']`; `get('flytta')?.name === 'moveWall'`; `get('nope')` is undefined.
  - `resolve('moveWall')` has `entry`; `resolve('moveWal')` has `finding` with `code === 'unknown-name'`, `data.nearest === 'moveWall'`, `data.valid` equal to the three names, and a message that contains `Menade du "moveWall"?`.
  - `resolve('zzzzzz')` has a finding whose `data` has no `nearest` key and whose message does not contain `Menade du`.
- `nearest('scal', ['moveWall', 'moveVertex', 'scale']) === 'scale'` (rule 1); `nearest('moveVertx', [...]) === 'moveVertex'` (rule 2); `nearest('x', [...])` is undefined.
- A duplicate name or alias in the constructor throws (`expect(() => new Registry(...)).toThrow()`).
