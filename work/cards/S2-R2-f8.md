Defect (checkpoint S2-R2, reviewer): the compare findings (`checks/index.ts` around lines 92-98) name walls and openings by id only. Contract §5 asks that a message name an element by position as well as by id, where the code knows the position.

Blocked: which position (the wall's end coordinates, or a point on the drawing in mm) and the wording are a design choice for the contract. Set ready with attempts 0 after the choice is written here.

## Decided and rewritten 2026-11-11 by the spec author (committed to the repo)
Decision: a message names a wall or an opening in the words the editor uses, with the id in brackets, using `describeRef` from `lib/plan/domain/names.ts` (it gives "väggen mellan Hall och Kök (2,4 m)", "yttervägg mot norr (6,1 m)", "dörren (900 mm) i …"). An id that `describeRef` does not know stays the bare id.

In `lib/plan/connector/checks/index.ts`, in the `compare` entry:
1. Add `import { cap, describeRef } from '../../domain/names'` at the top (`Plan` is already imported there).
2. After the line `    const out: Finding[] = []` add
```ts
    const name = (plan: Plan, id: string) => {
      const d = describeRef(plan, id)
      return d === id ? id : `${cap(d)} (${id})`
    }
```
3. Replace the six message strings:
   - position: `Väggen ${w.id} ligger ${w.diffMm >= 0 ? '+' : ''}${w.diffMm} mm från referensen (${w.axis}).` becomes `${name(c.plan, w.id)} ligger ${w.diffMm >= 0 ? '+' : ''}${w.diffMm} mm från referensen (${w.axis}).`
   - thickness: `Väggen ${w.id} är ${w.thickness} mm tjock mot ${w.refThickness} i referensen.` becomes `${name(c.plan, w.id)} är ${w.thickness} mm tjock mot ${w.refThickness} i referensen.`
   - missing opening: `Referensen har ${m.kind} ${m.refId} i ${m.wallId}; planen saknar den.` becomes `Referensen har ${name(ref.plan, m.refId)}; planen saknar den.`
   - extra opening: `Planen har ${m.kind} ${m.id} i ${m.wallId} som referensen saknar.` becomes `Planen har ${name(c.plan, m.id)} som referensen saknar.`
   - wall only in the reference: `Väggen ${id} finns bara i referensen.` becomes `${name(ref.plan, id)} finns bara i referensen.`
   - wall only in the plan: `Väggen ${id} finns bara i planen.` becomes `${name(c.plan, id)} finns bara i planen.`
   The codes, refs and `data` do not change.
