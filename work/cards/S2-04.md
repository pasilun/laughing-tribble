1. `lib/plan/mcp/format.ts`: add the word `export` before `function brief` (it is private now). Change nothing else in that file.
2. `lib/plan/connector/findings.ts`:
```ts
import { finding } from './answer'
import type { Finding as CheckFinding } from '../domain/checks'
import type { Finding } from './types'

// A finding of `checkPlan` as a contract finding: id = code, plus ':' + ref when it has one; refs = [ref] when it has one.
export function fromCheck(f: CheckFinding): Finding

// What an edit changed in the findings. The key of a finding is `${level}|${message}`; `fresh` are the findings of
// `after` whose key is not in `before` (as contract findings), `gone` counts the findings of `before` whose key is not in `after`.
export function freshFindings(before: CheckFinding[], after: CheckFinding[]): { fresh: Finding[]; gone: number }

// The standard findings. All level 'error'.
export const notFound = (id: string): Finding            // code 'not-found', refs [id], message `Dokumentet ${id} finns inte`
export const badArgument = (name: string, why: string): Finding   // code 'bad-argument', refs [name], message `Argumentet ${name}: ${why}`
export const staleRevision = (base: number, current: number): Finding
// code 'stale-revision', data { base, current },
// message `Dokumentet har ändrats: senaste revision är ${current}, du utgick från ${base}. Läs det med get och gör om ändringen.`
export const invalidOperation = (message: string): Finding
// code 'invalid-operation', data { reason: message }, message = message. When the message starts with
// `operation N` (a number), refs = [`op${N}`], otherwise no refs.
```
3. `lib/plan/connector/changes.ts`:
```ts
import { brief } from '../mcp/format'
import type { Plan } from '../domain/types'
import type { Changed } from './types'

// What differs between two revisions, by id, in the same lists as `changedSince` in lib/plan/mcp/format.ts
// (vägg → kind 'wall', öppning → 'opening', inredning → 'fixture', rum → 'room', mått → 'dimension').
// what: `tillagd: ${brief(x)}`, `ändrad: ${brief(x)}` or `borttagen`. When the sheet or title block differs add
// { kind: 'sheet', id: 'sheet', what: 'ändrad' }. At most 40 entries; if there are more, the 41st is
// { kind: 'more', id: '', what: `… och ${n} till` } with n the number left out.
export function changedList(old: Plan, now: Plan): Changed[]
```
Read `changedSince` in `lib/plan/mcp/format.ts` and follow its logic exactly; do not change it.

Tests (`e2e/connector-findings.spec.ts`, pure; use `demoPlan`, `applyOps` and `checkPlan` as `e2e/plan-model.spec.ts` does):
- `fromCheck({ level: 'error', code: 'title-block', message: 'm' })` has id `title-block` and no `refs`; with `ref: 'v1'` the id is `title-block:v1` and `refs` is `['v1']`.
- Take `demoPlan()` and a copy whose `sheet.titleBlock.address` is `''`. `freshFindings(checkPlan(a), checkPlan(b))` gives exactly one fresh finding with code `title-block` and `gone === 0`; with the arguments swapped it gives `fresh` empty and `gone === 1`.
- `changedList(demoPlan(), applyOps(demoPlan(), [{ op: 'update', kind: 'opening', id: 'ny-oppning', patch: { width: 1000 } }]).plan)` equals `[{ kind: 'opening', id: 'ny-oppning', what: expect.stringContaining('ändrad') }]`.
- Adding a note does not change the list (notes are not listed): `changedList(plan, plan with a new note)` is `[]`.
- Deleting wall `a-hall`: the list has `{ kind: 'wall', id: 'a-hall', what: 'borttagen' }` (it may have more entries for its openings).
- `staleRevision(1, 3).data` equals `{ base: 1, current: 3 }`; `invalidOperation('operation 2 (add): m').refs` equals `['op2']`; `invalidOperation('x').refs` is undefined.
