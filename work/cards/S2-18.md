Do: the scope `audit`: the plan against the drawing it was traced from (`auditPlan`, which `plan_audit` uses). Each audit item becomes a finding: its id (`wall:w3`, `door:o4`, `plan:no-source`) is the finding id, the code is `audit-` plus the part of the id before the colon, and an item that can be mended carries its operations in `fix`. `against` may hold `source` (a source id) and `printed_outer_mm` (`{width, length}`).
The code below was written and run by the spec author in a scratch copy of the repository (typecheck, lint and the card's tests passed). Copy it as it is; if something does not compile or a test fails, say so in your report instead of redesigning.

1. `lib/plan/connector/checks/index.ts`: add `import { auditPlan } from '../../assist/audit'` at the top, and this entry at the end:
```ts
export const audit: CheckEntry = { name: 'audit', summary: 'The plan against the drawing it was traced from; findings carry the fix',
  run: async (c) => {
    const po = c.against.printed_outer_mm as { width?: unknown; length?: unknown } | undefined
    const printed = po && num(po.width) !== undefined && num(po.length) !== undefined ? { width: po.width as number, length: po.length as number } : undefined
    const items = await auditPlan(c.id, c.plan, { sourceId: typeof c.against.source === 'string' ? c.against.source : undefined, printed })
    return { findings: items.map((i) => finding({ id: i.id, code: `audit-${i.id.split(':')[0]}`, level: i.level, message: i.text, refs: [i.id], ...(i.fix ? { fix: i.fix as Array<Record<string, unknown>> } : {}), ...(i.fixText ? { data: { fix_text: i.fixText } } : {}) })) }
  } }
```
2. `lib/plan/connector/registries/index.ts`: add `audit` to the import from `'../checks'` and to the list: `[permit, review, audit, finish]`.

Test: add to `e2e/connector-check.spec.ts`:
