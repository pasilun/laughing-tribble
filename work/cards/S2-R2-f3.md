Defect (checkpoint S2-R2, reviewer): `check` with scope `audit` on the demo plan (no source) returns `next: check audit` again. It should offer `source upload_link`. Cause: `nextCalls` (`next.ts` around lines 31-32) only returns the upload call when the plan has no walls.

Blocked: the fix (return the upload call whenever there is no source) changes the answer for a plan with walls, and the existing test `e2e/connector-next.spec.ts` expects the demo plan (which has walls and no source) to give `check` with scope `audit` (`expect(nextCalls(demo, 4, { openIssues: 2 }).next[0]).toMatchObject({ tool: 'check', arguments: { id: 'd', scope: ['audit'] } })`). That existing assertion must change, and the card does not authorise it. Needs an authorisation quoted from the file as it is now, naming the assertion and its new expected value, then set ready with attempts 0.

## Decided and rewritten 2026-11-11 by the spec author (committed to the repo)
Decision: the audit compares a plan with its source drawing, so it is only offered when the plan has a source (or an underlay). A plan with walls and no source is a plan made from measurements: the next step skips the audit and goes on to the rooms and the finish step. (An upload is not suggested for it: a measured plan has no drawing to upload.)

In `lib/plan/connector/next.ts` replace the line `  if (state.openIssues === undefined || state.openIssues > 0)` with `  if (hasSource && (state.openIssues === undefined || state.openIssues > 0))`. Nothing else changes in that file.

Authorised edit of one existing assertion: in `e2e/connector-next.spec.ts`, test `nextCalls follows the plan`, the line
`  expect(nextCalls(demo, 4, { openIssues: 2 }).next[0]).toMatchObject({ tool: 'check', arguments: { id: 'd', scope: ['audit'] } })`
is replaced by these three lines (`cal` is defined earlier in the test):
```ts
  const withSource = { ...demo, sources: cal.sources }
  expect(nextCalls(withSource, 4, { openIssues: 2 }).next[0]).toMatchObject({ tool: 'check', arguments: { id: 'd', scope: ['audit'] } })
  expect(nextCalls(demo, 4).next.some((n) => n.tool === 'check' && JSON.stringify(n.arguments.scope) === '["audit"]')).toBe(false)
```
Nothing else in that file changes.

Test: add to `e2e/connector-check.spec.ts`:
```ts
test('check: a plan without a source is not sent round the audit again', async ({ request }) => {
  const a = await makePlan(request, 'Check noaudit')
  const au = (await connector(request, 'check', { id: a.id, scope: ['audit'] })).structuredContent!
  expect((au.next ?? []).some((n) => n.tool === 'check' && JSON.stringify(n.arguments.scope) === '["audit"]')).toBe(false)
})
```
