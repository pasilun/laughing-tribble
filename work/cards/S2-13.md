Do: `get`, reading a document. It does what `plan_get` does (read it in `lib/plan/mcp/tools-read.ts`) without a picture (pictures are `view`'s job). Do not change `plan_get`.

`lib/plan/connector/handlers/get.ts`: `export async function get(args: Args): Promise<ToolResult>`; every return is `toToolResult(answer(…), { summary })`.

Steps:
1. **Arguments:** `id` non-empty string; `parts` an array of strings when given; `since` an integer when given; `format` a string when given. Otherwise `badArgument`.
2. **format:** `'text'` (default) or `'json'`; anything else is `unknownName`-style: use a local `new Registry('formats-of-get', 'format', [{ name: 'text', summary: 'The listing as text' }, { name: 'json', summary: 'The whole plan as data' }])` and its `resolve`.
3. **parts:** each name resolved with `PARTS.resolve` (from `./../registries`); collect unknown-name findings, answer them and stop.
4. **Load:** `loadPlan(id)`; null is `notFound(id)`.
5. **Body:** with `since`: `old = loadPlan(id, since)`; null is `notFound`-like `badArgument('since', 'revisionen finns inte')`; body = `Ändrat sedan revision ${since}:\n` + (`changedSince(old.plan, rev.plan)` from `../../mcp/format`, or `Inget har ändrats sedan dess.` when empty). Without `since`: `summarisePlan(rev.plan, parts)` (`parts` undefined when none given).
6. **Summary text:** `Revision ${rev.meta.n} (${rev.meta.message})\n${body}\n\n${links(rev.plan, rev.meta.n)}` (`links` from `../../mcp/format`).
7. **Answer:** `ok: true`, `id`, `revision: rev.meta.n`, `data: { name: rev.plan.name }`; for `format: 'json'` also `data.plan` = the plan with `underlay.src` replaced by `'…'` when there is an underlay (as `plan_get` with `include_json` does).

In `lib/plan/connector/handlers/index.ts` replace the `get` entry. Change nothing else there.

Tests (`e2e/connector-get.spec.ts`, API tests with `makePlan`, `connector`, `legacy`):
- default: `get { id }` → `ok: true`, `revision: 1`, text contains `Väggar` and `Öppningar` and `Revision 1`; exactly one content block (no picture).
- parts: `get { id, parts: ['walls'] }` → text contains `Väggar` and does not contain `Öppningar`.
- unknown part: `parts: ['wals']` → `findings[0].code === 'unknown-name'`, `findings[0].data.nearest === 'walls'`.
- since: after one edit with the old `plan_edit` (`{ plan_id, base_revision: 1, message: 'x', ops: [update opening ny-oppning width 1000] }`), `get { id, since: 1 }` → text contains `Ändrat sedan revision 1` and `ny-oppning`; `revision: 2`.
- json: `get { id, format: 'json' }` → `structuredContent.data.plan.walls` is an array with more than 5 entries and `data.plan.id === id`.
- format: `format: 'jsno'` → `findings[0].data.nearest === 'json'`.
- unknown plan: `findings[0].code === 'not-found'`.
