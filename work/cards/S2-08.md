Do: add the four tools that write, and the function that lists all ten. Same rules as card S2-07: copy the text exactly.

In `lib/plan/connector/tools.ts` add, below `READ_SPECS`:
```ts
const EDIT = { readOnlyHint: false, destructiveHint: false, idempotentHint: false }
const MANAGE = { readOnlyHint: false, destructiveHint: true, idempotentHint: false }
const EXPORT = { readOnlyHint: false, destructiveHint: false, idempotentHint: true }
export const WRITE_SPECS: ToolSpec[] = [ … four entries … ]

// The ten tools in the order of the contract: guide, list, get, check, view, scan, edit, source, manage, export.
export function connectorTools(): ToolSpec[]
```
`connectorTools()` returns the six read specs and four write specs ordered as in `TOOL_NAMES` (`lib/plan/connector/types.ts`); it throws an Error when a name is missing or twice.

The four entries:

1. `edit` (annotations `EDIT`) — description: `Planstudio: changes a document with small operations, saved as a new revision all-or-nothing. Pass base_revision from get; a stale one is refused. Use dry_run to see the effect first. The operations are listed by guide topic "ops". Example: {"id":"my-plan","base_revision":3,"ops":[{"op":"update","kind":"opening","id":"d1","patch":{"width":900}}]}.` — schema: `schema({ id: str('The document.'), base_revision: int('The revision you last read with get.'), ops: { type: 'array', description: 'The operations, applied in order, all or none.', items: { type: 'object', properties: { op: str('The operation name.') }, required: ['op'] } }, dry_run: bool('Work everything out, save nothing.'), message: str('The revision note, in Swedish.'), image: bool('Also return a picture of the sheet. Default false.') }, ['id', 'base_revision', 'ops'])`
2. `source` (`EDIT`) — `Planstudio: gets a source drawing into a document and places it: an upload link, add, calibrate, straighten. action names the step; see guide topic "vocabulary". A chat attachment cannot reach a tool: ask the user to open the upload link.` — `schema({ id: str('The document.'), base_revision: int('The revision you last read, for actions that change the document.'), action: str('Which step.'), args: obj('Arguments of the action. See guide.'), dry_run: bool('Work everything out, save nothing.') }, ['id', 'action'])`
3. `manage` (`MANAGE`) — `Planstudio: creates, copies, renames, tags, shares, trashes and restores documents. action names what to do; see guide topic "vocabulary". Deleting moves a document to the trash. Example: {"action":"create","args":{"name":"Kallare Lundagatan"}}.` — `schema({ action: str('What to do.'), id: str('The document, for actions that need one.'), args: obj('Arguments of the action. See guide.') }, ['action'])`
4. `export` (`EXPORT`) — `Planstudio: writes the sheets as PDF, PNG, SVG or DXF, or returns a link to open the document. format names the output; see guide topic "vocabulary". Example: {"id":"my-plan","format":"pdf"}.` — `schema({ id: str('The document.'), format: str('Which output.'), options: obj('Options of the format. See guide.') }, ['id', 'format'])`
