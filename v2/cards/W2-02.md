Why: renders need a bounding box for every element (to crop around an id, to place a label). One function gives it for rooms, walls and openings.

Files: `v2/crates/core/src/api.rs` (add to it); re-export `RectMm`, `element_rect`, `element_ids` from `lib.rs`.

Interface:

```rust
/// An axis-aligned rectangle in mm; x0 <= x1 (west to east), y0 <= y1 (north to south).
#[derive(Clone, Copy, Debug, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub struct RectMm { pub x0: Mm, pub y0: Mm, pub x1: Mm, pub y1: Mm }

impl RectMm {
    pub fn width(&self) -> Mm;   // x1 - x0
    pub fn height(&self) -> Mm;  // y1 - y0
    /// Smallest rectangle holding both.
    pub fn union(&self, other: &RectMm) -> RectMm;
    /// Grow by `m` mm on every side.
    pub fn pad(&self, m: Mm) -> RectMm;
}

/// The rectangle of one element: a room name (its solved inner faces), a wall id
/// (`W:…`, its body), or an opening id (`O:…`). `None` for an unknown id.
pub fn element_rect(resolved: &Resolved, id: &str) -> Option<RectMm>;

/// Every room name, wall id and opening id, sorted: rooms (by name), then walls, then openings.
pub fn element_ids(resolved: &Resolved) -> Vec<String>;
```

Rules:
- **Room:** `RectMm { x0: west, y0: north, x1: east, y1: south }` from `resolved.rooms`.
- **Wall:** the wall body, the same extents `solve_json` writes for `interior_walls` (`x: [min,max]`, `y: [min,max]`). Call the code that already computes them; do not compute them a second way. For outer walls, the body is the node line plus the thickness on the side away from the room (§9.2 step 2, "grows outward"); if week one has no function for outer bodies, compute it from the wall's `from`/`to` nodes, `thickness` and `reference`.
- **Opening:** along its face from `at` to `at + width` (origin rule §9.3: from the west end on north/south faces, from the north end on east/west faces), across the thickness of the wall it sits in.

Test (in api.rs), fixture A via `load`:
- `element_rect(r, "Garderob")` == `{0, 0, 1860, 2360}`.
- `element_rect(r, "W:Garderob.east|Hall.west")` == `{1860, 0, 1981, 1113}` (§7.6 list).
- `element_rect(r, "W:Vardagsrum.north|WC.south")` == `{3081, 990, 5541, 1113}`.
- `element_rect(r, "O:WC.west:1")` == `{3081, 240, 3171, 690}` (door at 240 width 450 in the 90 mm Hall.east|WC.west wall, x 3081–3171).
- `element_rect(r, "Nope")` is None.
- `element_ids(r)` starts with `["Garderob", "Hall", "Sovrum", "Vardagsrum", "WC"]` and contains `"O:WC.west:1"`.
