```rust
pub struct ResolvedFixture {
    pub id: String,              // "F:<Room>.<side>:<n>", numbered per face by `at`, then kind word
    pub kind: FixtureKind,
    pub face: FaceRef,
    pub x: (Mm, Mm), pub y: (Mm, Mm),   // rectangle, (min, max)
    pub label: Option<String>,
    pub phase: Phase,
}
```
`Resolved` gains `pub fixtures: BTreeMap<String, ResolvedFixture>`.

Geometry (D44). Let the room rectangle be r, the face span `(lo, hi)` as for openings (west→east on north/south faces, north→south on east/west faces), `a0 = lo + at`, `a1 = a0 + width`. Out from the face into the room, `b0 = offset`, `b1 = offset + depth`:
- North face: x = (a0, a1), y = (r.north + b0, r.north + b1)
- South face: x = (a0, a1), y = (r.south − b1, r.south − b0)
- West face: y = (a0, a1), x = (r.west + b0, r.west + b1)
- East face: y = (a0, a1), x = (r.east − b1, r.east − b0)
**Balcony** is the exception: it lies outside. With t = the thickness of the wall segment on that face that contains the point a0 (the first wall in `walls` whose `face` or `other` is this face and whose extent along the face contains a0; 0 if none): South face: y = (r.south + t + b0, r.south + t + b1); North: y = (r.north − t − b1, r.north − t − b0); East: x = (r.east + t + b0, r.east + t + b1); West: x = (r.west − t − b1, r.west − t − b0).

E019 (Error) for a fixture that is not a balcony and whose rectangle is not inside r (touching the faces is inside): args what = `Fixture {kind word}`, face, at, room; refs [face as `Room.side`]. The fixture is left out. A balcony is only checked along the face: a0 ≥ lo and a1 ≤ hi, else E019 the same way. A fixture whose room has no rectangle is skipped silently.

In `resolve_with`: place the fixtures after the openings; E019 is an error like E004 (in draft mode the fixture is just left out). `element_ids` lists fixture ids after the opening ids; `element_rect` returns the rectangle.

Authorised mechanical test edits: struct literals of the changed types in existing tests get the new fields with empty or default values; nothing else in those tests changes.
