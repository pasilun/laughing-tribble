Files: `v2/crates/render/src/render.rs`; `v2/crates/core/src/diagnostics.rs` (new `Code::E011`, Error, template, wording tests). The suggestion uses `strsim` and the `SUGGEST_MIN` (0.85) constant from `dsl/resolve.rs`, as E001 does.

E011 template: `Unknown element "{id}".{ Did you mean "{suggestion}"?} Use a room name, or a wall or opening id from get.` The `{ Did you mean …}` part appears only when a `suggestion` arg is given (same pattern as E001 in diagnostics.rs).

Rule 1 of W2-13 (content rectangle) becomes:
- `region == None`: as before (all elements, padded 500 mm).
- `Region::Id(id)`: `element_rect(resolved, id)` padded by **600 mm**. If it is `None`: return `Err(Diagnostic { code: E011, severity: Error, message, span: None, refs: vec![id], data: json!({"id": id, "suggestion": s}) })` where `s` is the id from `element_ids` with the highest Jaro–Winkler score if that score ≥ 0.85, else JSON null (and no suggestion arg).
- `Region::RectMm([x, y, w, h])`: exactly that rectangle, no padding. If `w` or `h` is below 1, use 1 (no error).

Everything outside the viewBox is clipped by SVG itself; draw all elements as before. Labels whose anchor is outside the image are already skipped (W2-15).

Tests (fixture A, View::Labels, max_tokens 1600):
- `crop_hall`: `Region::Id("Hall")` → `viewport.origin_mm == [1381, -600]`, `mm_per_px == 2.5`, `size_px == [920, 926]` (Hall is x 1981–3081, y 0–1113; padded 2300 × 2313 mm).
- `crop_rect`: `Region::RectMm([0, 0, 1000, 500])` → origin [0, 0], mm_per_px 1.0, size [1000, 500].
- `unknown_id_suggests`: `Region::Id("Hal")` → Err E011 with message `Unknown element "Hal". Did you mean "Hall"? Use a room name, or a wall or opening id from get.`
- `unknown_id_no_suggestion`: `Region::Id("Zzz")` → message `Unknown element "Zzz". Use a room name, or a wall or opening id from get.`
- `crop_labels_subset`: the Hall crop's `labels` include `Hall` and do not include `WC`'s room label if WC's centre is outside the crop (WC centre x 4356 > 1381 + 2300).
