Do: Let a CLI user work without the MCP server. Add `plan-scan = { path = "../scan" }` to `crates/cli/Cargo.toml` if it is not there.

**`plan source add FILE IMAGE [--name N] [--mm-per-px X] [--scale S --dpi D] [--at X,Y] [--role R] [--year Y] [--view plan|elevation]`**
(`crates/cli/src/main.rs`):
1. Read and parse `FILE`; on a parse error print it and exit 1.
2. Read `IMAGE`; `plan_scan::decode::decode` (E024 text on failure, exit 1).
3. Name = `--name` or `free_source_name(stem of IMAGE, existing names)`.
4. Write `<FILE's dir>/sources/<FILE's stem>/<name>.png` through `plan_scan::assets`.
5. Build the `source` statement, apply it to the parsed plan, and when `ok` write the canonical text back to `FILE` through a temp file and rename (like `fmt --write`). Print `Added source <name> (<w>×<h> px) to <FILE>`; on an apply error print the diagnostics and exit 1 without writing.
6. Log under `<FILE's dir>/.history/<FILE's stem>/` with author `"user"`, the source line as the patch, `changes: 1`.

**`plan history FILE [--limit N]`**:
- read `<FILE's dir>/.history/<FILE's stem>/log.jsonl`; print newest first: `N  <date>  <author>  <summary>  (<changes> change(s))`, with the patch indented under it when it is non-empty;
- `No history for <FILE>.` and exit 0 when the log is missing;
- `--limit` (default 20); a bad value is the usual usage error.

Tests (`crates/cli/tests/source.rs`):
- copy fixture A to a temp dir, write a 4×3 PNG next to it, run `source add`; the plan gains the line, `sources/lgh154-a/scan.png` exists, a second run makes `scan-2`;
- `source add --scale 100 --dpi 200` writes `mm_per_px 12700`;
- `history` prints the entry and honours `--limit 1`;
- a missing image and a text image exit 1 with E024.

Done when: the tests pass and the workspace gate is green.
