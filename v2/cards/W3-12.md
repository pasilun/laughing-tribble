Problem found by the audit: every outer corner of a drawing has a square hole, because each outer wall's rectangle only spans its room face. (Fixture A: the corner x −300…0, y −300…0 is empty.)

Rule (D28, drawing only; the core model and the wall ids do not change): an outer wall on a **north or south** face is drawn longer, so it covers the corner square.

```rust
/// The rectangle to draw for `wall`: (x0, y0, x1, y1) in mm.
pub(crate) fn corner_rect(wall: &Wall, resolved: &Resolved) -> (Mm, Mm, Mm, Mm)
```
```
start with (x0, y0, x1, y1) = (wall.x.0, wall.y.0, wall.x.1, wall.y.1)
if wall.kind != Outer: return it
let Some(face) = &wall.between.0; let Some(r) = resolved.rooms.get(&face.room); else return it
if face.side is North or South:
    corner_y = (side == North) ? r.north : r.south
    // west end
    if wall.x.0 == r.west:
        if some outer wall v has v.between.0 == (face.room, West) and
           ((side == North && v.y.0 == r.north) || (side == South && v.y.1 == r.south)):
            x0 -= v.thickness
    // east end
    if wall.x.1 == r.east:
        if some outer wall v has v.between.0 == (face.room, East) and (same y test as above):
            x1 += v.thickness
return (x0, y0, x1, y1)
```
East and west walls are returned unchanged. "Some outer wall v" searches `resolved.walls.values()`; several segments can come from one face (ids ending `#2`), any of them that passes the test counts.

In svg.rs: `wall_element` takes `resolved` as a second argument and draws the rectangle from `corner_rect` (x, y, width = x1 − x0, height = y1 − y0). The id label stays centred on the wall's own extents (`wall.x`, `wall.y`), so labels do not move. `drawn_elements` passes `resolved`.
