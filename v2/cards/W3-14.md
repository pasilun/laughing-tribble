Interface:
```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Paper { A4, A3 }                 // always landscape
impl Paper {
    pub fn size_mm(self) -> (f64, f64)    // A4 → (297.0, 210.0), A3 → (420.0, 297.0)
    pub fn name(self) -> &'static str     // "A4", "A3"
}
pub struct SheetOptions { pub paper: Paper, pub scale: Option<u32>, pub title: String, pub date: Option<String> }
pub struct Sheet { pub svg: String, pub paper: Paper, pub scale: u32 }
pub fn sheet(resolved: &Resolved, opts: &SheetOptions) -> Result<Sheet, Diagnostic>
```

Layout (D31), paper size (W, H) in mm, everything in the SVG in paper mm:
1. **Extent** of the plan in model mm: the union of every room rectangle and every wall's `corner_rect`: (minx, miny, maxx, maxy); `ew = maxx − minx`, `eh = maxy − miny`. No rooms and no walls: use (0, 0, 1000, 1000).
2. **Available area:** `aw = W − 30`, `ah = H − 45` (10 mm margin, 15 mm title strip at the bottom, 5 mm padding). A4: 267 × 165. A3: 390 × 252.
3. **Scale n** (drawing is 1:n): if `opts.scale` is `Some(n)`, use it; else the first n in `[20, 25, 50, 100, 200, 500, 1000]` with `ew/n ≤ aw && eh/n ≤ ah`. Whichever way n was chosen, if it does not fit: `Err` E018 (Error) with args paper = name, scale = n, and `fit` = the first list value that fits (leave `fit` out when none fits or when the scale was automatic); `data: json!({"paper": name, "scale": n, "fit": fit_or_null})`. An explicit scale of 0 is treated as not fitting.
4. **Placement:** `k = 1.0 / n`; `tx = 15 + (aw − ew·k)/2 − minx·k`; `ty = 15 + (ah − eh·k)/2 − miny·k`.
5. **SVG**, in this order:
   - `<svg xmlns="http://www.w3.org/2000/svg" width="{W}mm" height="{H}mm" viewBox="0 0 {W} {H}">`
   - white background rect over the page;
   - frame: `<rect x="10" y="10" width="{W−20}" height="{H−20}" fill="none" stroke="#000000" stroke-width="0.35"/>`;
   - strip line: `<line x1="10" y1="{H−25}" x2="{W−10}" y2="{H−25}" stroke="#000000" stroke-width="0.35"/>`;
   - `<g id="plan" transform="translate({tx} {ty}) scale({k})">` holding `drawn_elements(resolved, RoomFonts { name: 3.5·n, area: 2.5·n }, 0.35·n)`, where every element that does **not** start with `<g class="room"` goes through `without_text` (wall and opening ids are not printed on a sheet), then for each room one more text: its clear size `{width} × {depth}` (mm, the × sign) centred at (cx, cy + 3.5·n) with font size 2.5·n, fill `#1a1a1a`, using the `text` helper; `</g>`;
   - title strip texts, font size 3.5, `font-family="{FONT_FAMILY}"`, baseline y = H − 15.5: the title (escaped) at x = 14 with `text-anchor="start"`; `Scale 1:{n} ({paper name})` at x = W/2 with `text-anchor="middle"`; the date, if any, at x = W − 14 with `text-anchor="end"`;
   - scale bar: `<line x1="{W/2 − 500/n}" y1="{H − 12}" x2="{W/2 + 500/n}" y2="{H − 12}" stroke="#000000" stroke-width="0.5"/>` and a text `1 m`, font size 2.5, centred at (W/2, H − 12.8), `text-anchor="middle"`;
   - `</svg>`.
