Do: `plan suggest`: W001 with the nearest facing faces as a concrete "measure X to Y" suggestion. Follow the spec sections listed above exactly; paths are relative to the repo root, the v2 workspace is in `v2/`.

Done when: Loose-room fixture → exact suggestion text. Plus `cd v2 && cargo fmt --check && cargo clippy -q -- -D warnings && cargo test -q` is green.

Candidate rule (fixed by the spec run of 2026-11-09, decision D5 in `docs/v2-agent-specs.md` §15). A loose component has no position on its axis, so "nearest" cannot use the distance on that axis. Use this ranking and nothing else:

```
for each loose component L on axis A (from components()), with B the other axis:
  candidates = []
  for a in rooms of the anchored component of A, in declaration order:
    for l in rooms of L, in declaration order:
      for dir in [After, Before]:
        on x: After  = (from a.east,  to l.west,  relation east_of)
              Before = (from l.east,  to a.west,  relation west_of)
        on y: After  = (from a.south, to l.north, relation south_of)
              Before = (from l.south, to a.north, relation north_of)
        overlap = length of the overlap of a's and l's solved spans on axis B
                  if both rooms are in B's anchored component, else 0 (never negative)
        candidates.push((overlap, a, l, dir))
  best = max overlap; ties: earliest a, then earliest l, then After before Before
  if there are no candidates (no anchored rooms): no suggestion, keep the W1-10 text
W001 args: axis words ("east–west" for x, "north–south" for y), room = l, from, to,
           relation, of = a, gap = plan.default_wall.value
```

Example (§6.4): `Not tied east–west: Förråd. Measure from Hall.east to Förråd.west, or add "Förråd east_of Hall gap 90".`
