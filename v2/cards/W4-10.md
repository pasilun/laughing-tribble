1. `pub enum Lang { En, Sv }`. `SheetOptions` gains `pub lang: Lang` and `pub block: BTreeMap<String, String>` (the plan's `title` map). Existing literals get `lang: Lang::En, block: BTreeMap::new()` (authorised, mechanical); CLI and MCP pass the plan's `title` map as `block`.
2. Words:
   | | En | Sv |
   |---|---|---|
   | scale text | `Scale 1:{n} ({paper})` | `Skala 1:{n} ({paper})` |
   | property | `Property` | `Fastighet` |
   | address | `Address` | `Adress` |
   | applicant | `Applicant` | `Sökande` |
   | drawing | `Drawing` | `Ritning` |
   | drawn_by | `Drawn by` | `Ritad av` |
   | date | `Date` | `Datum` |
   | description | `Description` | `Beskrivning` |
3. Title strip, when `block` is empty: exactly as today (apart from the Swedish scale text).
4. Title strip, when `block` is not empty: the strip keeps its 15 mm height and is split into two text rows, font size 2.8, baselines at `H − 19.5` and `H − 14`. Left column at x = 14 (`text-anchor="start"`): row 1 `{title}` (the sheet title as today), row 2 `{Property word}: {property}` if present, followed by `, {address}` if present (the address alone if there is no property). Right column at x = W − 14 (`text-anchor="end"`): row 1 `{Drawing word}: {drawing}` if present, then ` · {Date word}: {date}` if present (`opts.date` wins over `block["date"]` when both exist); row 2 `{Applicant word}: {applicant}` if present, then ` · {Drawn by word}: {drawn_by}` if present. `description`, if present, replaces `{title}` in row 1 of the left column. The scale text and the scale bar stay in the middle as today (scale text baseline moves to `H − 19.5`).
5. CLI `plan pdf`: new option `--lang en|sv` (default en). MCP `export`: optional `lang` (`"en"` | `"sv"`, default `"en"`), and make `format` optional with default `"pdf"` (the reviewer of run 1043 found it was required).
