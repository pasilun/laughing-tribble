Files: `v2/crates/server/src/lib.rs`.

Arguments:

```rust
#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
pub struct ApplyArgs {
    /// The plan: a file name under the server's root, without `.plan`. A new id creates the plan.
    pub plan_id: String,
    /// DSL statements to add or replace; a line starting with "- " removes the matching statement.
    pub patch: String,
    /// Compute everything and change nothing.
    #[serde(default)] pub dry_run: bool,
}
```

Tool: `#[tool(name = "apply", description = APPLY_DESCRIPTION, annotations(read_only_hint = false, destructive_hint = true, idempotent_hint = true))]`, `APPLY_DESCRIPTION = "Change a plan with a DSL patch. All or nothing: if any error results, nothing changes. Statements replace the statement with the same key (room by name, relation by subject, kind and room, measure by its faces, opening by face and position). Use dry_run to preview."`

Flow:

```
path check: store.path(plan_id)?                        # E021
text = match store.load(plan_id):
    Ok(t) => t
    Err(d) if d.code == E020 => format!("plan \"{plan_id}\"\n")   # new plan, default walls
    Err(d) => return tool error [d]
plan = plan_core::dsl::parse(&text) or tool error [E006]     # a stored file that doesn't parse can't be patched
result = plan_core::apply(&plan, &args.patch, args.dry_run)
saved = false
if result.ok && !args.dry_run:
    store.save(plan_id, &print(result.plan))?              # E023 → tool error
    saved = true
n = result.diff.len()
summary = if !result.ok { "Not applied: {e} error(s). The plan is unchanged." }
          else if args.dry_run { "Dry run: {n} change(s) would be applied; nothing saved." }
          else { "Applied {n} change(s); saved." }
structured: {"plan_id", "ok", "dry_run", "saved", "diff", "diagnostics", "summary"}   # not a tool error, even when ok is false
```

Tests (fixtures copied to a temp root as `a.plan` from fixture A):

- `apply_saves`: same patch without dry_run → `saved == true`; reloading the file parses and has 5 openings; the file equals `print` of its own parse (canonical).

- `apply_bad_id`: plan_id `a/b` → tool error E021.
