Interface (write exactly this; `Region` is used from W2-16, accept it now and treat every region as `None` in this card):

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum View { Plan, Labels }
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Region { Id(String), RectMm([i64; 4]) }
#[derive(Clone, Debug, PartialEq)]
pub struct RenderOptions { pub view: View, pub region: Option<Region>, pub max_tokens: u32 }
#[derive(Clone, Debug, PartialEq)]
pub struct Rendered { pub svg: String, pub viewport: Viewport, pub labels: Vec<PlacedLabel> }

/// Draw a resolved plan. Lengths in mm, x east, y south.
pub fn render(resolved: &plan_core::Resolved, opts: &RenderOptions) -> Result<Rendered, plan_core::Diagnostic>;
```

For this card `PlacedLabel` is `pub struct PlacedLabel;` placeholder in render.rs and `labels` is empty; W2-14 replaces it.

Rules:
1. Content rectangle = union of `element_rect` of every id in `element_ids(resolved)`, padded by 500 mm. `vp = fit([x0, y0, x1 − x0, y1 − y0], opts.max_tokens)`.
2. Root element, exactly: `<svg xmlns="http://www.w3.org/2000/svg" width="{W}" height="{H}" viewBox="{ox} {oy} {vw} {vh}">` where W, H = `vp.size_px`, ox, oy = `vp.origin_mm`, vw = W × mm_per_px, vh = H × mm_per_px (format with `{}`, so 7146 not 7146.0 — write integers when the value is whole). So 1 px is exactly `mm_per_px` mm.
3. First child: `<rect x="{ox}" y="{oy}" width="{vw}" height="{vh}" fill="white"/>`.
4. Grid: a `<g id="grid">` with a thin line (`stroke="#d0d0d0"`, `stroke-width` = 1 px = `mm_per_px`) at every multiple of 1000 mm inside the viewBox, both axes.
5. Elements as W1-23 draws them, but every stroke width and font size given in px is multiplied by `mm_per_px` so it is that many pixels in the image. Font size for room labels 12 px.
6. Scale bar: a `<g id="scale">` holding a black horizontal line 1000 mm long from x = ox + 20 px to x = ox + 20 px + 1000 mm, at y = oy + vh − 30 px, stroke-width 3 px, and the text `1 m` (font-size 12 px, `text-anchor="middle"`) centred over the line, 6 px above it. Here "N px" always means N × `mm_per_px` in viewBox units.
