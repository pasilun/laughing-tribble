Grammar (D45): `stub = "stub" face "at" INT "length" INT [ "thickness" INT ] [ "offset" INT ] [ "bearing" ] [ phase ]`. New keywords: `stub`, `length`. A stub is a piece of wall that starts on a room face and runs `length` mm straight into the room. `thickness` defaults to `default_wall`'s value at resolve time (store `Option<Mm>`); `offset` (default 0) moves its start away from the face, which makes a free-standing wall.

Do:
1. intent.rs: `pub struct Stub { pub face: FaceRef, pub at: Mm, pub length: Mm, pub thickness: Option<Mm>, pub offset: Mm, pub bearing: bool, pub phase: Phase }`; `Plan` gains `pub stubs: Vec<Stub>` (`#[serde(default)]`).
2. Parser, printer (after the `wall` lines and before the `door` lines, sorted by face then `at`; print `thickness` only when Some, `offset` only when not 0), patch key (face, at).
3. Resolved: `pub struct ResolvedStub { pub id: String /* "S:<Room>.<side>:<n>" numbered per face by at */, pub face: FaceRef, pub x: (Mm, Mm), pub y: (Mm, Mm), pub thickness: Mm, pub bearing: bool, pub phase: Phase }`; `Resolved` gains `pub stubs: BTreeMap<String, ResolvedStub>`. Geometry: exactly the fixture rule of W5-03 with width = thickness and depth = length (so on a north face the stub is x (lo + at, lo + at + thickness), y (r.north + offset, r.north + offset + length)). Outside the room → E019 with what = `Stub`; left out.
