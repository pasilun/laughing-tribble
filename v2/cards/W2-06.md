Why: `parse(print(p)) == p` (§7.2) can only hold for a plan whose lists are already in canonical order, because the printer sorts. The round-trip property (W2-08) compares against `canonicalize(p)`.

Files: `v2/crates/core/src/dsl/printer.rs` only. Add `pub use printer::canonicalize;` to `dsl/mod.rs`.

Interface: `pub fn canonicalize(plan: &mut Plan)`. It reorders, it never changes a value.

Order (it must be exactly the order `print` writes the lines, read from `statement_lines`, `relation_lines` and `lone_align_lines`):
1. `relations`: for each room in `plan.order`: its directional relations (subject == room) in keyword order east_of, west_of, south_of, north_of, keeping their relative order within a keyword; then its `Align`s whose first room is this room and that list at least two rooms, in their current order. After all rooms: every `Align` with exactly one room, in current order. Any relation not placed by these rules (subject not in `order`) goes last, in current order.
2. `measures`: stable sort by `(face_key(from), face_key(to))`.
3. `wall_overrides`: stable sort by `face_key(face)`.
4. `openings`: stable sort by `(kind rank, face_key(face), at.value)` with Door 0, Window 1, Passage 2 (the printer writes doors, then windows, then passages).

Refactor so `print` and `canonicalize` cannot drift: make `statement_lines` and `relation_lines` iterate over a canonicalized clone (`let mut p = plan.clone(); canonicalize(&mut p);`) instead of sorting themselves. The printed text must not change: every existing printer test stays as it is and must pass.

Tests (in printer.rs):
- `canonicalize_is_idempotent`: for fixtures A, B, C: `canonicalize` twice equals once.
- `canonical_plan_round_trips_exactly`: for fixtures A, B, C: `let mut p = parse(src)?; canonicalize(&mut p); assert_eq!(parse(&print(&p))?, p);` (full equality, not the same-items helper).
- `openings_order_is_kind_face_at`: a plan with `window B.south at 10 …`, `door A.north at 5 …`, `door A.north at 1 …` canonicalizes to door A.north 1, door A.north 5, window B.south 10.

Done when: the three tests pass, all existing printer tests pass unchanged, and `cd v2 && cargo fmt --check && cargo clippy -q -- -D warnings && cargo test -q` is green.
