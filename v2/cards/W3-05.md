Files: `v2/crates/core/src/solve/components.rs`; test expectations named below.

Problem found by the audit: for two rooms with no relation, `plan check` prints
`W001 warning Not tied east–west: B. Measure from {from} to {to}, or add "B {relation} {of} gap {gap}".`
while `plan suggest` prints the filled text. The cause: `with_suggested_data` copies only `data` from `suggest_one` and keeps the placeholder message.

Do: make `with_suggested_data` return the whole diagnostic from `suggest_one` (message and data), so `resolve` reports the filled text. Update its doc comment. `components()` itself keeps writing the placeholder text (its own unit test stays as it is).

Authorised test edits: only expected strings of W001 messages that contain `{from}` in tests of `resolve`, `load`, the CLI snapshots (`crates/cli`) and the server tests, replaced by the filled text the code now produces. Do not touch the test `components` has for its own placeholder text (components.rs, the assertion with `C {relation} {of} gap {gap}`).

Test to add (resolved.rs or components.rs test module): rooms `A 2000 x 1000 source laser` and `B 1500 x 1000 source laser`, no relations. `resolve` gives two W001 with messages
- `Not tied east–west: B. Measure from A.east to B.west, or add "B east_of A gap 90".`
- `Not tied north–south: B. Measure from A.south to B.north, or add "B south_of A gap 90".`
