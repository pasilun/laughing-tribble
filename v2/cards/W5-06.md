Files: `v2/crates/core/src/intent.rs`, `dsl/lexer.rs`, `dsl/parser.rs`, `dsl/printer.rs`, `validate.rs`, `resolved.rs`, `tests/common/mod.rs`; `v2/crates/render/src/svg.rs`, `sheet.rs`, `render.rs`.

Why: an L-shaped room is written as two rectangles joined by `open`. Today each rectangle prints its own name and area.

Grammar (D46): `room NAME size "x" size [src] [apartment STRING] [ "part" NAME ] [phase]`. New keyword `part`. `room Matvra 2400 x 1500 part Kok` means: this rectangle belongs to the room Kok.

Do:
1. intent.rs: `Room` gains `pub part_of: Option<RoomName>`. Parser (the parent name is name-checked: E001), printer (after `apartment`, before the phase).
2. validate.rs: `part` naming the room itself → E015 with subject = the room, relation = `part`, of = the room (message `"A part A" relates a room to itself.`). A parent that is itself a part → E015 the same way with subject = the room and of = the parent (only one level is allowed).
3. Resolved gains `pub room_parts: BTreeMap<RoomName, RoomName>` (part → parent), for rooms that have a rectangle and whose parent has one.
4. Drawing (`room` in svg.rs, and the room label requests in render.rs): a part gets no name and no area text. Its parent's area text is the sum of the parent's own rectangle and all its parts. The parent's label stays at the centre of the parent's own rectangle.
5. sheet.rs: the clear-size text (`{w} × {d}`) is not printed for a part, nor for a parent that has parts.
6. `solve_json` is unchanged (`areas_mm2` stays per rectangle).
7. Generator (authorised): rooms keep `part_of: None`. Authorised mechanical test edits: struct literals of the changed types in existing tests get the new fields with empty or default values; nothing else in those tests changes.

Tests:
- parser/printer: `room Matvra 2400 x 1500 source laser part Kok` round-trips; `part` of an unknown room → E001; `room A 1000 x 1000 part A` → E015 `"A part A" relates a room to itself.`
- svg (rooms `Kok 2400 x 4000 source laser`; `Matvra 2400 x 1500 source laser part Kok` with `south_of Kok open` and `align west Kok`): the SVG contains `13.20 m²` once, does not contain `3.60 m²` or `9.60 m²`, and contains no text `Matvra`.
- render plan view: labels contain `Kok 13.20 m²` and no label for Matvra.
- sheet: contains neither `2400 × 1500` nor `2400 × 4000`.
- fixtures A, B, C unchanged.
