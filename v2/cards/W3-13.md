Files: `v2/crates/render/src/svg.rs` (`opening_element`).

Do: for an opening with `kind == Door` and `hinge == Some(h)`, add one `<path>` to its `<g>` (after the `<line>`, before the label): the leaf, then a quarter circle to the other jamb.

Geometry (D29), all in mm. Let `w = end − start`, `(lo, hi)` the wall's extent across its thickness (already computed in the function), `side = opening.face.side`, `room = opening.face.room`.
1. Target room: `opens_into` if given, else `room`. `inward = (target == room)`.
2. Face line `c`: the wall face on the target room's side. The opening's own room lies beyond `lo` for a South or East face (wall is south/east of the room) and beyond `hi` for a North or West face. So:
   - side South or East: `c = inward ? lo : hi`
   - side North or West: `c = inward ? hi : lo`
3. Direction `s` of the leaf, away from the wall into the target room: for South or East, `s = inward ? −1 : +1`; for North or West, `s = inward ? +1 : −1`.
4. Hinge position along the face: `a = start` when h is West or North, `a = end` when h is East or South. The other jamb `b` is the other of start/end.
5. Points (x, y):
   - face North or South (wall runs east–west): H = (a, c), L = (a, c + s·w), J = (b, c)
   - face East or West (wall runs north–south): H = (c, a), L = (c + s·w, a), J = (c, b)
6. `cross = (L.x − H.x)·(J.y − H.y) − (L.y − H.y)·(J.x − H.x)`; `sweep = 1` if cross > 0 else `0`.
7. Path: `<path d="M {H.x} {H.y} L {L.x} {L.y} A {w} {w} 0 0 {sweep} {J.x} {J.y}" fill="none" stroke="{colour}" stroke-width="{stroke/2}"/>` with the door colour already used for the line and `stroke` the function's stroke argument. Integers print without decimals.

Doors without a hinge, windows and passages get no path.

Worked example (fixture A): `door WC.west at 240 width 450 hinge south opens Hall`. Wall `W:Hall.east|WC.west` spans x 3081…3171; start 240, end 690, w 450. Target Hall ≠ WC → outward. Side West: c = lo = 3081, s = −1. Hinge south → a = 690, b = 240. H = (3081, 690), L = (2631, 690), J = (3081, 240). cross = (−450)(−450) − 0 = 202500 > 0 → sweep 1.
