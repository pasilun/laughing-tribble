Files: `v2/crates/core/src/build/openings.rs`.

Problem found by the audit: `door A.east … opens C` is accepted when C is not at that wall.

Do: in `place_openings`, for an opening that was placed in wall `w` (a `BuiltWall`) and has `opens_into == Some(room)`: the allowed rooms are `w.face.room` and, when `w.other` is `Some(f)`, `f.room`. If `room` is not one of them: push E017 (Error). Args: face = `{Room}.{side}` of the opening's own face (use the file's existing `face_label`), room, and options = the allowed room names sorted by name, each in double quotes, joined by ` or ` (`"A" or "B"`; one name for an outer wall: `"A"`). `refs: [opening id]`; `data: json!({"opening": id, "room": room, "allowed": [names]})`.

- Same with `opens B`: none. Fixture A (`door WC.west … opens Hall`): none.
- Room `A 3000 x 2000`; `door A.north at 500 width 900 hinge west opens A`: none.
