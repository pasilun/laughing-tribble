Do: Scale a source so that printed dimensions are right, with no model in the loop.

**`crates/scan/src/calibrate.rs`** (pure, no I/O):
```rust
pub struct Measurement { pub a: (i64, i64), pub b: (i64, i64), pub mm: i64, pub label: Option<String> }
pub struct Residual { pub label: String, pub drawn_mm: i64, pub residual_mm: i64, pub residual_pct_tenths: i64 }
pub struct Calibration {
    pub factor_x: f64, pub factor_y: f64,
    pub mm_per_px_x: i64, pub mm_per_px_y: i64,   // thousandths
    pub rms_mm: i64,
    pub residuals: Vec<Residual>,
    pub axes_disagree: bool,
}
pub fn calibrate(mm_per_px: (i64, i64), ms: &[Measurement]) -> Result<Calibration, String>;
```
Rules (D52):
- Ignore a measurement with `mm <= 0` or zero length; if none are left the error is `at least one measurement with a length and a positive mm is needed`.
- Horizontal set: `|dx| >= |dy|`; vertical set: the rest. `dx = b.x - a.x` with its sign; square it in the sums.
- `k = Σ(d · mm) / Σ(d²)` over each set.
- A set with no measurements copies the other set's `k` (isotropic fallback).
- `mm_per_px_axis` = `round(mm_per_px_axis * k)` (at least 1).
- Residual per measurement: `drawn = hypot(dx·kx, dy·ky)`, rounded; `residual = drawn − mm`; percent in tenths.
- `axes_disagree` when both sets exist and `|kx − ky| / ((kx + ky)/2) > 0.005`.

**Printer helper** `pub fn source_line(source: &Source) -> String` in `crates/core/src/dsl/printer.rs` (the same text the canonical printer writes).

**Tool** `source_calibrate {plan_id, source, measurements: [{a:{x,y}, b:{x,y}, mm, label?}], anchor?: {x,y}, dry_run?: bool}` in `crates/server/src/lib.rs`:
1. Load and parse the plan; find the source by name (E025 with a Jaro–Winkler suggestion when unknown); its current `mm_per_px` is `(v, v)` when `Some`, else `(1000, 1000)` (the nominal 1 mm/px).
2. `calibrate`; its error is a tool error (a clear message, not a panic).
3. New `at` = `anchor + (old_at − anchor) · k` per axis, rounded; anchor defaults to (0,0).
4. Patch = `- <old source line>` and `+ <new source line>` (the line with the new `mm_per_px` and `at`), applied all-or-nothing. `dry_run` computes and saves nothing.
5. Return `{factor_x, factor_y, mm_per_px_x, mm_per_px_y, rms_mm, residuals, axes_disagree, patch, saved, rev}` plus `diagnostics: [W040]` when the axes disagree. W040 never blocks the save.

**Diagnostics** (`crates/core/src/diagnostics.rs`): add
`W040 Source "{name}": the x and y scales differ by {pct} %; check the printed dimensions.`
(`pct` one decimal, severity warning, refs `[name]`).

Tests:
- pure: one horizontal 1000 px → 5000 mm gives kx 5, ky 5 (isotropic), zero residuals; one horizontal and one vertical with different factors gives both; a 0.6 % difference sets `axes_disagree`;
- server: a plan with `source scan "scan.png" mm_per_px 1 at 100,50`, two measurements → patch applied, new `mm_per_px` and `at` are on the line, `rev` returned;
- unknown source → E025; a zero-length measurement → error; `dry_run` leaves the text unchanged.
