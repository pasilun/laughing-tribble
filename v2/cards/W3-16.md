Files: `v2/crates/cli/src/main.rs`; new test `v2/crates/cli/tests/pdf.rs` (model it on `tests/png.rs`).

Do: add the command, parsed like `png_command` (options in any order after FILE; `-o` is required). Defaults: paper a3, scale automatic, title = the plan's name (`Resolve.plan.name`), no date. Steps: read and load the file as `png_command` does (parse errors and plan errors are printed as in `check`, exit 1); `plan_render::sheet`; `plan_render::pdf`; write the file; print one line of JSON to stdout: `{"paper":"a3","scale":25,"bytes":N}`. A diagnostic from `sheet` or `pdf` (E018, E012) is printed like other diagnostics (`E018 error …`) and gives exit 1. Unknown paper, a scale that is not a positive integer, or a missing `-o`: usage error, exit 2. Add the line to `USAGE`:
`  plan pdf <file> -o <out.pdf> [--paper a4|a3] [--scale N] [--title TEXT] [--date TEXT]`

- `--paper a2` → exit 2.
