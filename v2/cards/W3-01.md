Files: `v2/crates/core/src/diagnostics.rs` only.

Do: add these variants to `Code` (with `#[serde(rename = "…")]`, `as_str`, and a `message` arm each), following the existing pattern exactly. No other file changes; nothing emits them yet.

| Code | Template (placeholders in braces) |
|---|---|
| E014 | `{what} is {value} mm; it must be at least 1 mm.` |
| E015 | `"{subject} {relation} {of}" relates a room to itself.` |
| E016 | `Openings {a} and {b} overlap by {d} mm on wall {wall}.` |
| E017 | `Door on {face} cannot open into "{room}"; use {options}.` |
| E018 | `Plan does not fit on {paper} at 1:{scale}.` and, only when a `fit` argument is given, append ` Use 1:{fit}.` (same optional pattern as E001's suggestion) |
| W005 | `Wall {id} is {t} mm thick; check the measurements around it.` |
| W020 | `Reference measure {from}→{to}: drawn {drawn}, measured {value} ({diff} mm).` |
| W030 | `Wall {id} is load-bearing and is demolished; this needs a structural engineer's drawings and calculation.` |
| W031 | `Wall {id} is a fire-cell boundary ({fire}) and is demolished; a fire protection description is required.` |
| W032 | `{kind} {id} is new and sits in load-bearing wall {wall}; this needs a structural engineer's statement.` |
| W033 | `{kind} {id} is new and sits in fire-cell boundary {wall} ({fire}); a fire protection description is required.` |
| I030 | `{kind} {id} is new and has no height; add "height <mm>" if the engineer needs it.` |

If the file has a function or table that maps a code to its default severity, add E… as Error, W… as Warning, I… as Info.

Tests (in the file's test module, one per code): call `message(code, &args)` and compare the full string. Examples that must hold:
- E014 with what="Room A width", value="0" → `Room A width is 0 mm; it must be at least 1 mm.`
- E018 with paper="A4", scale="20", fit="50" → `Plan does not fit on A4 at 1:20. Use 1:50.`; without `fit` → `Plan does not fit on A4 at 1:20.`
- W020 with from="B.east", to="A.east", drawn="500", value="520", diff="20" → `Reference measure B.east→A.east: drawn 500, measured 520 (20 mm).`
- `Code::W030.as_str() == "W030"` and serde gives `"W030"`.

Done when: the tests pass, and `cd v2 && cargo fmt --check && cargo clippy -q -- -D warnings && cargo test -q` is green.
