
`Plan` gains `#[serde(default)] pub sources: Vec<Source>`, kept in declaration order.

Grammar (`§7.1`):
```
source = "source" NAME STRING [ "mm_per_px" DEC ] [ "at" INT "," INT ] [ "role" ROLE ]
         [ "year" INT ] [ "view" VIEW ] ;
ROLE = "archive" | "before" | "after" | "other" ;
VIEW = "plan" | "elevation" ;
DEC  = digits "." 1*3digit ;          (* 6.35 = 6350 thousandths *)
```
`at` values may have a leading `-`.

Lexer (`crates/core/src/dsl/lexer.rs`): add `TokenKind::Dec(i64)` (thousandths) for digits `.` digits when the next char is not `m`, and `TokenKind::Minus`. Keep `1.86m` = 1860 as it is. More than 3 fraction digits is E006. Add keywords `mm_per_px`, `role`, `year`, `view`, `archive`, `before`, `after`, `other`, `elevation`.

Parser: `source` at statement level; duplicate name gives **E026** (same shape as E002, with both line numbers); a file containing `/`, `\` or equal to `..` gives E006 ("a file name without a folder"); `mm_per_px 0` gives E006.

Printer: after the `title` lines and before the rooms, in declaration order, one line each. Omit `at 0,0`, `role other`, `view plan` and `year` when absent. Print `mm_per_px` as an integer when divisible by 1000, else with the decimals trimmed (`6.35`, `12.7`).

`Source "{name}" is declared twice (lines {a} and {b}).`
