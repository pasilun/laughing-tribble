Grammar (D44), the same addressing as openings:
`fixture = "fixture" KIND face "at" INT [ "width" INT ] [ "depth" INT ] [ "offset" INT ] [ "label" STRING ] [ phase ]`
New keywords: `fixture`, `depth`, `offset`, `label`. KIND is an ordinary word read after `fixture` (not a keyword), one of the twelve below; anything else is E006 with expected `a fixture kind (kitchen, stove, sink, wc, shower, bath, radiator, exhaust, shaft, plug, box, balcony)`.

Default size (width along the wall × depth out from it), used when `width` or `depth` is left out:
| kind | width | depth |
|---|---|---|
| stove, sink | 600 | 600 |
| wc | 400 | 700 |
| shower | 900 | 900 |
| bath | 1600 | 700 |
| radiator | 1000 | 100 |
| exhaust | 150 | 150 |
| plug | 100 | 100 |
| kitchen, shaft, box, balcony | none: both `width` and `depth` are required (E006: expected `"width"` or `"depth"` at the place where it is missing) |

Do:
1. intent.rs:
```rust
pub enum FixtureKind { Kitchen, Stove, Sink, Wc, Shower, Bath, Radiator, Exhaust, Shaft, Plug, Box, Balcony }
pub struct Fixture {
    pub kind: FixtureKind,
    pub face: FaceRef,          // the wall it stands against
    pub at: Mm,                 // along the face, same origin rule as openings (§9.3)
    pub width: Mm,              // along the face (defaults filled in by the parser)
    pub depth: Mm,              // out from the face
    pub offset: Mm,             // distance from the face; 0 when left out
    pub label: Option<String>,
    pub phase: Phase,
}
```
   `Plan` gains `pub fixtures: Vec<Fixture>` (`#[serde(default)]`). Add `FixtureKind::word(self) -> &'static str` (lower case) and `FixtureKind::default_size(self) -> Option<(Mm, Mm)>`.
2. Parser: as the grammar; the face's room is name-checked like an opening's (E001).
3. Printer: after the `passage` lines, sorted by face then `at` then kind word: `fixture {kind} {face} at {at}` + ` width {w}` and ` depth {d}` (both printed when the kind has no default **or** either differs from the default; neither printed otherwise) + ` offset {n}` if not 0 + ` label "{text}"` + phase word if not existing.
4. commands.rs: patch key of a fixture is (face, at, kind); `- fixture stove Kok.north at 200` removes it.
5. Generator (authorised): zero to two fixtures on faces of generated rooms, kinds `stove` (no sizes, default) and `kitchen` (width 1800, depth 600), `at` in 0..2000, offset 0, no label, any phase.
