Interface: `pub fn arb_plan() -> impl Strategy<Value = Plan>`. Every plan it makes is already canonical (call `plan_core::dsl::canonicalize` at the end, via `prop_map`).

What it generates (keep exactly to this; each limit is what the DSL text can carry):
- `name`: `"[A-Za-z0-9 ]{0,20}"` (no `"`, no newline).
- `default_wall`, `default_outer_wall`: `qty()` (below).
- Rooms: 1 to 6. Names from `"[A-Za-zÅÄÖåäö][A-Za-zÅÄÖåäö0-9_]{0,7}"`, filtered so they are unique and not one of the DSL keywords: `plan default_wall default_outer_wall room x apartment existing demolish new east_of west_of south_of north_of open gap align measure to reference door window passage at width height hinge opens source tol wall thickness north east south west laser tape printed drawing estimated assumed`. `order` = generation order.
- Room size: width and depth each `Option<Mm>` in `1..=20000` (None = `?`), and **one** source spec shared by both (the printer writes one `source` clause per room). Phase any of the three. `apartment`: `None` or `"[A-Za-z0-9 ]{1,8}"`.
- `qty()`: value `0..=20000`, source any of the six, tolerance either the source default or `0..=100`.
- Relations: for room i ≥ 1, 0–2 directional relations with subject room i and `of` one of rooms 0..i, gap `Open` or `Wall(qty())`; plus 0–2 `Align`s with a random side and 1–3 distinct rooms, the first one being any room.
- Measures: 0–3, `from` and `to` faces on the same axis (both north/south or both east/west), value `qty()`, `reference` any bool.
- Wall overrides: 0–2, any face, thickness `qty()`.
- Openings: 0–3, any kind, any face, `at` = `qty()`, `width` value `1..=3000` with **the same source and tolerance as `at`** (the printer writes one clause from `at`), `height` `None` or `1..=3000`, `hinge` None or any side, `opens_into` None or any room, phase any.
- Faces always name generated rooms.
