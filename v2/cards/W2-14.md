Interface (write exactly this):

```rust
/// A label to place. Pixel coordinates, x right, y down (same as the image).
#[derive(Clone, Debug, PartialEq)]
pub struct LabelReq { pub id: String, pub text: String, pub anchor_px: [f64; 2], pub priority: u8 }

#[derive(Clone, Debug, PartialEq, serde::Serialize)]
pub struct PlacedLabel {
    pub id: String, pub text: String,
    pub anchor_px: [f64; 2],
    pub center_px: [f64; 2],   // centre of the text box
    pub size_px: [f64; 2],     // [w, h] of the text box
    pub leader: bool,          // true when the box is not on the anchor: draw a line anchor → box
    pub overlaps: bool,        // true when no free spot was found
}

pub const CHAR_W_PX: f64 = 7.5;   // DejaVu Sans at 12 px, average advance, rounded up
pub const LABEL_H_PX: f64 = 16.0;

/// Place labels inside a `size_px` image without overlaps where possible.
pub fn place(reqs: &[LabelReq], size_px: [u32; 2]) -> Vec<PlacedLabel>;
```

Pseudo-code:

```
reqs sorted by (priority, id)            # output in this order
placed = []
for r in reqs:
    w = CHAR_W_PX * r.text.chars().count() + 6; h = LABEL_H_PX; W = w/2 + 10
    offsets = [(0,0),(0,-20),(0,20),(-W,0),(W,0),(0,-40),(0,40),(-W,-20),(W,-20),(-W,20),(W,20)]
              + [(0,-(40+20j)), (0, 40+20j) for j in 1..=6]
    for (dx,dy) in offsets:
        c = anchor + (dx,dy); box = [c.x-w/2, c.y-h/2, c.x+w/2, c.y+h/2]
        if box inside [0,0,img_w,img_h] (edges may touch) and box intersects no placed box:
            place at c; leader = (dx,dy) != (0,0); overlaps = false; next r
    # nothing fits
    c = anchor clamped: cx = if w <= img_w { clamp(anchor.x, w/2, img_w - w/2) } else { img_w/2 }, same for y with h
    place at c; leader = false; overlaps = true
intersects(a, b) = a.x0 < b.x1 && b.x0 < a.x1 && a.y0 < b.y1 && b.y0 < a.y1   # touching is not overlapping
```

Tests (labels.rs; all numbers worked out):
1. Image [400, 200]. Reqs: `("R", "Hall", [100,100], 0)`, `("W", "W:x", [100,100], 1)`. Result: R at [100,100], size [36,16], no leader; W at [100,80], size [28.5,16], leader true.
2. Image [400, 200]. One req `("G", "Garderob", [5,5], 0)`: placed at [48,25] (offset (W, 20), W = 43), leader true, overlaps false.
3. Same reqs as test 1 given in reverse order → identical output.
4. Image [10, 10]. One req `("H", "Hall", [3,3], 0)` → center [5,5], overlaps true, leader false.
5. Property-style: 30 labels with random anchors in a [800, 600] image (fixed seed list in the test, no new dependency) → no two placed boxes with `overlaps == false` intersect.
