Interface (write exactly this):

```rust
/// One edge after distribution. Lengths in mm.
#[derive(Clone, Debug, PartialEq, serde::Serialize)]
pub struct AdjustedEdge {
    pub edge: usize,        // index into the edge slice
    pub origin: String,     // edges[edge].origin
    pub value: Mm,          // the stated value
    pub adjusted: Mm,       // round_half_even(x[to] − x[from]) after distribution
    pub shift: f64,         // (x[to] − x[from]) − value, unrounded
}

#[derive(Clone, Debug, PartialEq)]
pub struct Distribution {
    /// New coordinate of every face of the component, rounded half-even.
    pub coords: BTreeMap<FaceKey, Mm>,
    /// Every edge of the component on this axis, in edge-index order.
    pub edges: Vec<AdjustedEdge>,
}

/// Spread the component's within-tolerance cycles over its edges (§6.2 step 5).
/// `coords` holds the first-pass coordinates from the spanning tree; the
/// component's root keeps its coordinate. Returns `None` if `wls` returns `None`.
pub fn distribute(edges: &[Edge], component: &Component, axis: Axis,
                  coords: &BTreeMap<FaceKey, Mm>) -> Option<Distribution>;
```

Pseudo-code:

```
faces = component.faces (declaration order); index[face_key] = position in faces
root = key(faces[0]); fixed = [(0, coords[root] as f64)]
soft = []; hard = []; member = []
for (i, e) in edges.enumerate() where e.axis == axis and key(e.from) in index and key(e.to) in index:
    member.push(i)
    if e.tolerance == 0: hard.push(Hard{a: index[from], b: index[to], value: e.value as f64})
    else:                soft.push(Soft{a: index[from], b: index[to], value: e.value as f64, weight: weight(e.tolerance)})
x = wls(faces.len(), &fixed, &soft, &hard)?
coords_out[face] = round_half_even(x[index[face]])
for i in member: d = x[to] − x[from]; AdjustedEdge{edge: i, origin, value, adjusted: round_half_even(d), shift: d − value}
```

`round_half_even(f: f64) -> Mm`: use `f.round_ties_even() as i64` (stable since Rust 1.77). Put it in `v2/crates/core/src/units.rs` as `pub fn round_half_even(f: f64) -> Mm` if it isn't there yet, with a test that 2.5 → 2, 3.5 → 4, −2.5 → −2.
