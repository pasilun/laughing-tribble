Do: Give every plan a readable history without a database yet (D55).

**`crates/scan/src/history.rs`** (file I/O; used by the server and the CLI). Add `serde = { version = "1", features = ["derive"] }`, `serde_json = "1"` and `chrono = { version = "0.4", default-features = false, features = ["clock"] }` to `crates/scan/Cargo.toml`:
```rust
#[derive(Serialize, Deserialize)]
pub struct Entry {
    pub rev: u32,             // 1, 2, …
    pub at: String,           // ISO 8601 UTC, e.g. "2026-11-10T21:06:00Z"
    pub author: String,       // "claude", "user" or "upload"
    pub patch: String,        // the DSL statements that were applied ("" for a plain save)
    pub changes: usize,       // ApplyResult.diff.len()
    pub summary: String,      // the tool's one-line summary
}
/// <root>/.history/<plan_id>/
pub fn history_dir(root: &Path, plan_id: &str) -> PathBuf;
pub fn list(root: &Path, plan_id: &str) -> Vec<Entry>;        // oldest first; empty when nothing is logged
pub fn next_rev(root: &Path, plan_id: &str) -> u32;           // last + 1, 1 when empty
pub fn append(root: &Path, plan_id: &str, entry: &Entry, text: &str) -> std::io::Result<()>;
/// Writes 000N.plan (the canonical text) then appends one JSON line to log.jsonl.
```

**Server**:
- `Store::save` stays as it is for exports and tests; add `Store::save_logged(plan_id, text, entry)` that writes the plan and then the history entry.
- `apply_value`: on a successful, non-dry-run save, build the entry (`author:"claude"`, the patch as sent, `changes` from the diff, the existing `summary`), call `save_logged`, and add `"rev": entry.rev` to the JSON. A failed or dry-run apply writes no history (and `rev` is the current one, or 0 when none).
- New tool `history {plan_id, limit?: usize (default 20)}` (read-only): `{ "plan_id", "rev": <current>, "entries": [ … newest first, at most limit … ] }`. Unknown plan is E020; a plan with no history has `rev: 0, entries: []`.

Tests:
- create a plan with `apply` → `rev` 1, `history` has one entry with the patch and `changes`;
- a second apply → rev 2; a failed apply and a dry run add nothing;
- `.history/<id>/0002.plan` equals the stored text; `log.jsonl` has two lines and parses as `Entry`;
- `history` limit 1 returns the newest; an unknown plan → E020; a plan saved before history exists → `rev 0`.

Done when: the tests pass and the workspace gate is green.
