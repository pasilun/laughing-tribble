Why: an MCP client (W2-20 `check` next steps) needs the suggested faces as data, not only as text, and a second choice when the user can't reach the first wall.

Files: the module where W1-24 builds the "Not tied" W001 and where W1-10 builds the unknown-size W001 (find them with `grep -rn "Code::W001" v2/crates/core/src`). Change only how `data` is filled and add the alternatives; the message text must stay exactly as it is.

Data (serde_json, keys exactly these):
- **Not tied:** `{"axis": "x"|"y", "room": l, "from": "<Room>.<side>", "to": "<Room>.<side>", "relation": "east_of"|…, "of": a, "gap": <default_wall mm>, "alternatives": [ {"from", "to", "relation", "of"}, … ] }`. The alternatives are the next candidates of the W1-24 ranking (same order: overlap desc, earliest a, earliest l, After before Before), at most 2, never repeating the main one. Empty array when there are none.
- **Unknown size:** `{"axis": "x"|"y", "room": r, "from": "r.west", "to": "r.east", "unknown": "width"}` or `{"axis": "y", "room": r, "from": "r.north", "to": "r.south", "unknown": "depth"}`.
- `refs` for both: the room names involved, sorted.

Tests (with the module's tests):
1. Plan
   ```
   room Hall 1000 x 2000 source laser
   room Förråd 800 x 2000 source laser
     align north Hall
   ```
   gives one W001 with message `Not tied east–west: Förråd. Measure from Hall.east to Förråd.west, or add "Förråd east_of Hall gap 90".` and data `{"axis":"x","room":"Förråd","from":"Hall.east","to":"Förråd.west","relation":"east_of","of":"Hall","gap":90,"alternatives":[{"from":"Förråd.east","to":"Hall.west","relation":"west_of","of":"Hall"}]}`.
2. Plan
   ```
   room A 1000 x 1000 source laser
   room B 1000 x 1000 source laser
     south_of A gap
   room C 500 x 1000 source laser
     align north B
   ```
   gives one W001 for C (x axis) with `from` `B.east`, `to` `C.west`, `relation` `east_of`, `of` `B` (overlap 1000 with B, 0 with A), and alternatives exactly `[{"from":"C.east","to":"B.west","relation":"west_of","of":"B"}, {"from":"A.east","to":"C.west","relation":"east_of","of":"A"}]`.
3. `room A 1000 x 1000 source laser\nroom B 1000 x ?\n  east_of A gap\n  align north A\n` gives the depth-unknown W001 for B with data `{"axis":"y","room":"B","from":"B.north","to":"B.south","unknown":"depth"}`.

Done when: the three tests pass, every existing W001 text test still passes unchanged, and `cd v2 && cargo fmt --check && cargo clippy -q -- -D warnings && cargo test -q` is green.
