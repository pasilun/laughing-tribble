Files: new `v2/crates/render/src/marks.rs`; `v2/crates/render/src/lib.rs` (`pub mod marks;`, re-export `Mark, MarkKind, render_marked`); `v2/crates/render/src/render.rs`.

Interface:
```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum MarkKind { Conflict, Missing, Suggest }      // red #c62828, amber #e08a00, blue #1565c0
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Mark { pub id: String, pub from: [i64; 2], pub to: [i64; 2], pub text: String, pub kind: MarkKind }

/// `render`, plus the marks drawn on top. Lengths in mm, x east, y south.
pub fn render_marked(resolved: &Resolved, opts: &RenderOptions, marks: &[Mark]) -> Result<Rendered, Diagnostic>
```
`render(resolved, opts)` becomes `render_marked(resolved, opts, &[])` and its output must not change by one byte when there are no marks.

Do, in `render_marked`:
1. Content rectangle: as today; when there is no region, also union in each mark's two points before the 500 mm padding.
2. Labels: after the room requests and before the wall requests, add one `LabelReq` per mark, in the order given: `id` = mark id, `text` = mark text, anchor = the midpoint of from and to in px, priority 0. A mark whose midpoint is outside the image gets no label.
3. SVG: after the scale bar and before the labels group, when `marks` is not empty, one group `<g id="marks">` with, per mark, in order: the line `<line x1 y1 x2 y2 stroke="{colour}" stroke-width="{2·mpp}"/>` from `from` to `to` (mm), then two end ticks, each a line of length `10·mpp` centred on an end point and perpendicular to the mark (for a vertical mark the ticks are horizontal; a mark that is neither horizontal nor vertical gets no ticks). `Missing` and `Suggest` lines also get `stroke-dasharray="{6·mpp} {4·mpp}"`.
4. In `labels_group`, a label whose id is a mark id is drawn with that mark's colour as `fill` (pass the marks in); other labels are unchanged.

Tests (marks.rs test module, fixture A, `View::Plan`, 1600 tokens):
- no marks: `render_marked(.., &[]).svg == render(..).svg`.
- one mark `{ id: "m1", from: [930, 0], to: [930, 4540], text: "stated 4490, drawn 4540 (50 mm)", kind: Conflict }`: the SVG contains `<g id="marks">`, contains `x1="930" y1="0" x2="930" y2="4540" stroke="#c62828"`, has exactly 3 `<line` elements inside the marks group, and `labels` contains an entry with id `m1`.
- a `Missing` mark's line contains `stroke-dasharray`.
- a mark from [0, 0] to [20000, 0] with no region: `viewport.origin_mm[0] + size_px[0] as f64 * mm_per_px >= 20000.0` (the picture grew to hold it).
