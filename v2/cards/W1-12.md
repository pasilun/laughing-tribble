Public interface (write exactly this):

```rust
/// One edge of a chain: the edge index and the direction it is walked
/// (+1 from `from` to `to`, −1 against it).
#[derive(Clone, Debug, PartialEq, Eq, serde::Serialize)]
pub struct ChainEdge { pub edge: usize, pub sign: i8 }

/// One cycle closed by a non-tree edge.
#[derive(Clone, Debug, PartialEq, Eq, serde::Serialize)]
pub struct CycleCheck {
    pub axis: Axis,
    pub stated: usize,             // index of the stated edge (highest index in the cycle)
    pub residual: Mm,              // stated value − implied value
    pub tolerance: Mm,             // sum of the tolerances of every edge in the cycle
    pub chain_a: Vec<ChainEdge>,   // the implied side, walked from stated.from to stated.to
    pub chain_b: Vec<ChainEdge>,   // [ChainEdge { edge: stated, sign: 1 }]
    pub conflict: bool,            // |residual| > tolerance
}

/// Check every non-tree edge of `axis`, in edge-index order.
pub fn check_cycles(edges: &[Edge], coords: &BTreeMap<FaceKey, Mm>, tree: &[TreeEdge], axis: Axis) -> Vec<CycleCheck>;
```

(`Axis` needs `serde::Serialize`; add the derive in graph.rs, serialized as `"x"`/`"y"` with `#[serde(rename_all = "lowercase")]`.)

Pseudo-code:

```
tree_set = { t.edge for t in tree }
parent[child] = (parent_face, edge_index) and depth[child] from tree; roots have no parent, depth 0
for i in 0..edges.len() where edges[i].axis == axis and i not in tree_set:
    a = key(edges[i].from); b = key(edges[i].to); v = edges[i].value
    # loop: walk the tree from a to b, then edge i backwards
    path = tree_path(a, b)            # list of ChainEdge from a to b (see below)
    loop = path + [ChainEdge{edge: i, sign: -1}]
    L = (coord[b] - coord[a]) - v     # signed sum of the loop
    s = the ChainEdge in loop with the largest edge index
    residual = s.sign * L
    tolerance = sum(edges[c.edge].tolerance for c in loop)
    chain_a = build_chain_a(loop, s)  # see below
    chain_b = [ChainEdge{edge: s.edge, sign: 1}]
    push CycleCheck{axis, stated: s.edge, residual, tolerance, chain_a, chain_b,
                    conflict: abs(residual) > tolerance}
```

Building `chain_a` (do it this way, no other way): rotate `loop` so that `s` is first, giving `[s, c1, c2, …, ck]`. If `s.sign == +1`, the loop leaves `s` at `edges[s].to`, so walking `c1…ck` goes from `s.to` back to `s.from`; chain_a is `ck, …, c1` reversed in order **and** each sign negated. If `s.sign == −1`, the loop leaves `s` at `edges[s].from`, so `c1…ck` already go from `s.from` to `s.to`; chain_a is `c1, …, ck` unchanged.

`tree_path(a, b)`: walk up from the deeper of a and b using `parent` until both are at the same depth, then step both up together until they meet (the lowest common ancestor). The part from a up to the ancestor is walked against the tree direction; the part from the ancestor down to b is walked with it. For each tree edge, `sign = +1` if the walk goes from `edges[e].from` to `edges[e].to`, else `−1` (compare the face keys).
