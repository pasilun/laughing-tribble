Do: Give the user a link to drop a drawing on, because a chat attachment cannot reach an MCP tool.

`crates/server/src/upload.rs` (new), dependencies `tiny_http = "0.12"` and `getrandom = "0.3"` in `crates/server/Cargo.toml`:

```rust
pub struct UploadLink { pub url: String, pub expires_in_s: u64 }
pub struct UploadServer { port: u16, jobs: Arc<Mutex<HashMap<String, Job>>> }
pub struct Job { pub plan_id: String, pub created: Instant }

impl UploadServer {
    /// Bind 127.0.0.1:0 once per PlanServer and spawn one thread that serves it.
    pub fn start(store: Store) -> std::io::Result<Self>;
    /// A new random 32-hex token (getrandom) and its URL /u/<token>.
    pub fn link(&self, plan_id: &str) -> UploadLink;
}
```

`PlanServer` keeps `upload: std::sync::Arc<std::sync::OnceLock<UploadServer>>` and starts it on the first `upload` call. `upload {plan_id}` (tool, read-only false because the upload will change the plan) returns
`{ "url": "http://127.0.0.1:<port>/u/<token>", "expires_in_s": 3600, "note": "Open the link, drop a PNG, JPEG or TIFF (max 30 MB), then read the plan again." }`.
The link (token) is valid for one upload and 3600 s; a second PUT gets 410.

Requests on the listener:
- `GET /u/<token>` → 200 HTML page: title "Planstudio: add a drawing", a file input, fields name / scale / dpi / role (select) / year, and a small script:
  `fetch(location.pathname + "?name=" + encodeURIComponent(file.name) + "&scale=…&dpi=…&role=…&year=…", { method: "PUT", body: file })`
  then replaces the page with the response text. No external assets, no multipart.
- `PUT /u/<token>` → 413 when `Content-Length` is over 30 MB; 410 for a used or unknown token; otherwise read the body to a file `<root>/uploads/<token>-<safe original name>` (the original name from `?name=`), then call `assets::add_source` with the query parameters. On success the response is 200 text: `Added source <name>. You can return to Claude.`; on failure 400 text with the diagnostic messages. The token is marked used before the body is read.

Tests (`crates/server/tests/upload.rs`, dev-dependency `ureq = "3"`):
- temp root and a plan file; `PlanServer::new`; call the tool value to get a URL;
- `ureq` PUT a small PNG with `?name=scan.png&scale=100&dpi=200`; the answer is 200, the plan has the source, the asset exists, `get json` lists it;
- a second PUT with the same token is 410; a 31 MB body is 413 (send the header and close); a text file gives 400 with E024.

Done when: the tests pass, the listener binds only `127.0.0.1`, and the workspace gate is green.
