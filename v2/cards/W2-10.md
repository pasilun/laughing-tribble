Why: a plan can resolve and still rest on guesses. This lists the readings worth taking next, worst first. It is **not** part of `resolve` or `plan check` (their outputs stay as week one); only `plan suggest` and the MCP `check` next steps use it.

Files: `v2/crates/core/src/diagnostics.rs` (new `Code::I020`, serialized `"I020"`, severity Info, its template and a wording test); create `v2/crates/core/src/solve/unmeasured.rs`; add `pub mod unmeasured;` and `pub use unmeasured::unmeasured;` to `solve/mod.rs`.

Template (I020): `{what} {value} mm has source {source} (±{tol} mm); measure {from} to {to} with the laser.`

Interface: `pub fn unmeasured(plan: &Plan) -> Vec<Diagnostic>`.

Rules:

```
items = []
for room in plan.order (declaration order):
    for (dim, q, from_side, to_side) in [(width, west, east), (depth, north, south)]:
        if q is Some and q.source in {Printed, Drawing, Estimated, Assumed}:
            items.push(what = "{room} {dim}", value = q.value, q, from = room.from_side, to = room.to_side)
for relation in plan.relations (in order), directional with Gap::Wall(q):
    if q.source in {Printed, Drawing, Estimated}:            # assumed gaps are default walls: skip
        (from, to) = east_of:  (of.west,      subject.east)
                     west_of:  (subject.west, of.east)
                     south_of: (of.north,     subject.south)
                     north_of: (subject.north, of.south)
        items.push(what = "Gap {subject} {kw} {of}", value = q.value, q, from, to)
drop an item if plan.measures has a non-reference measure between the same two faces (either order)
stable sort items by tolerance, largest first (ties keep the order above)
each item -> Diagnostic { code: I020, severity: Info,
    message: message(I020, what, value, source (lower case, as serde writes it), tol, from, to),
    span: None, refs: [room] or [subject, of] sorted,
    data: {"what", "value", "source", "tolerance", "from", "to"} }
```

Test `fixture_a_unmeasured` (fixture A) gives exactly these three messages, in this order:
1. `Gap Hall east_of Garderob 121 mm has source drawing (±30 mm); measure Garderob.west to Hall.east with the laser.`
2. `Gap Vardagsrum south_of WC 123 mm has source drawing (±30 mm); measure WC.north to Vardagsrum.south with the laser.`
3. `Hall width 1100 mm has source assumed (±10 mm); measure Hall.west to Hall.east with the laser.`

Test `measured_gap_is_dropped`: fixture A text plus `measure Garderob.west to Hall.east = 3081 source laser` gives only items 2 and 3.

Test `i020_exact_wording` in diagnostics.rs for one filled template.
