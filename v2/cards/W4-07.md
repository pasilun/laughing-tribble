```rust
/// The picture of `after`, with the differences from `before` drawn on top.
pub fn render_diff(before: &Resolved, after: &Resolved, opts: &RenderOptions) -> Result<(Rendered, DiffCounts), Diagnostic>
```
Rules (D40). Compare walls by id, then openings by id:
- **added**: id only in `after`. **removed**: id only in `before`. **changed**: id in both, and the extents differ (walls: `x`, `y` or `thickness`; openings: `start`, `end` or `wall`).
- Rectangle of a wall: (x.0, y.0, x.1, y.1). Rectangle of an opening: use `plan_core::element_rect(resolved, id)`.
- Picture: `render_marked(after, opts, &[])`, except that with no region the content rectangle is the union of both plans' content (so removed parts are inside). Then, before the labels group, `<g id="diff">` with one `<rect>` per difference, in this order: removed (ids sorted), changed, added:
  - removed: the `before` rectangle, `fill="none" stroke="#c62828" stroke-width="{2·mpp}" stroke-dasharray="{6·mpp} {4·mpp}"`
  - changed: the `after` rectangle, `fill="#e08a00" fill-opacity="0.6"`
  - added: the `after` rectangle, `fill="#2e7d32" fill-opacity="0.6"`
  Each rect has `data-id="{id}"` and `data-diff="removed|changed|added"`.
- If you cannot reach the content rectangle or the insertion point from outside `render.rs`, add a `pub(crate)` helper there (for example `render_with(resolved, opts, marks, extra_rect: Option<RectMm>, extra_svg: &str)`) and let `render_marked` call it; output without marks or extras must stay byte for byte the same.

CLI: `plan png AFTER.plan -o OUT.png --diff BEFORE.plan` (other options as before; `--view` is ignored with `--diff` and the plain plan view is used). Both files must load without errors (else print the diagnostics, exit 1). JSON line gains `"diff":{"added":A,"removed":R,"changed":C}`. Add `[--diff BEFORE]` to the usage texts.
