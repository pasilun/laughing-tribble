Files: `v2/crates/core/src/resolved.rs`.

Problem found by the audit: two rooms placed on top of each other (both `east_of A gap` and `align north A`) are accepted silently. E005 has a template but nothing emits it.

Do: in `resolve`, after the axes are solved (and after W3-03's removal of unplaced rooms), before `built_walls`:
1. Collect the **loose rooms**: every room listed in `Component.rooms` of a component with `anchored == false`, on either axis. (Gather this inside the per-axis loop, where `comps` is available.)
2. Take the rectangles from the existing `rooms(plan, &coords)` helper. For every pair of rooms (a, b) with a before b in `plan.order`, both having a rectangle and neither loose:
   `dx = min(a.east, b.east) − max(a.west, b.west)`, `dy = min(a.south, b.south) − max(a.north, b.north)`. If `dx > 0 && dy > 0`: push E005 (Error) with args a, b, dx, dy; `refs: [a, b]`; `data: json!({"a": a, "b": b, "dx": dx, "dy": dy})`; `span: None`.
3. Then the existing `if has_error(&diagnostics) { return (None, diagnostics); }` must run before `built_walls` (add one if there is none at that point).

Rooms that only touch (dx or dy equal to 0) do not overlap.

Tests (resolved.rs test module), plan header as in the other tests (`default_wall 90`, `default_outer_wall 300`):
- Rooms `A 2000 x 1000`, `B 1500 x 1000` (`east_of A gap`, `align north A`), `C 1500 x 1000` (`east_of A gap`, `align north A`), all `source laser`: resolved is `None`; exactly one E005 with message `B and C overlap by 1500 × 1000 mm.`
- Rooms `A 2000 x 1000` and `B 1500 x 1000` with no relation (B is loose): no E005, the two W001 as before.
- Fixture A: no E005.

If an existing test fails because its plan really has overlapping rooms, do not edit it: report the test name in your answer and stop.
