Rules, in this order, at most 10 entries in total (stop adding at 10):
1. Each Error diagnostic, in order:
   - E003: `{first line of message} Ask the user which value to trust, then fix it with apply.`
   - any other Error: `Fix: {first line of message}`
2. Each W001, in order: `Ask the user to measure {data.from} to {data.to} with the laser, then apply "measure {data.from} to {data.to} = <mm> source laser".`
3. Each W003, in order: `Ask the user: {message}`
4. Any other Warning (W004, W005, W020, …): `Check: {message}`
5. If `plan` is Some and there was no Error: the first 3 diagnostics of `plan_core::solve::unmeasured(plan)`, each as `Optional: {message}`.
6. If the list is still empty: `Nothing to do: the plan resolves with no errors or warnings.`
Info diagnostics (I010 …) are not listed.

`check` passes `Some(&r.plan)` when `load` succeeded, `None` on a parse/name error.
