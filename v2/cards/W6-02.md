Do: Create the workspace member `crates/scan` (crate `plan-scan`, lib `plan_scan`), with no dependency on the server.

`Cargo.toml`: `image = { version = "0.25", default-features = false, features = ["png", "jpeg", "tiff"] }`, `serde` only if a type is returned to clients (it is not).

`src/decode.rs`:
```rust
pub struct Decoded {
    pub png: Vec<u8>,          // 8-bit greyscale PNG
    pub width_px: u32,
    pub height_px: u32,
    pub dpi: Option<f64>,      // from PNG pHYs or JPEG/TIFF metadata, when the decoder gives it
}
pub fn decode(bytes: &[u8]) -> Result<Decoded, String>;
```
- Sniff the format from the bytes (`image::guess_format`); PNG, JPEG and TIFF only, anything else is the message `unsupported format <x>; use PNG, JPEG or TIFF`.
- Reject a long edge over 12 000 px with `image is <w>×<h> px; the limit is 12 000 px on the long edge`.
- Convert with `DynamicImage::to_luma8` and encode with `image::codecs::png::PngEncoder`. The output must decode with `image::load_from_memory` as `Luma8`.
- `dpi`: PNG `pHYs` or the TIFF/JPEG density when present; otherwise `None`.

`src/scale.rs`:
```rust
/// 1:scale at `dpi` scan resolution: 25.4 / dpi * scale mm per printed pixel,
/// in thousandths (D50). Rounded half away from zero.
pub fn mm_per_px_from(scale: u32, dpi: f64) -> i64;   // (100, 200.0) -> 12700
```
Reject `dpi <= 0`, `scale == 0` and results over 1 000 000 thousandths (1 m/px) with a short `String` error.

`src/lib.rs` also exports `pub fn png_size(bytes: &[u8]) -> Option<(u32, u32)>` (reads the IHDR without decoding the pixels; `image::ImageReader::new(Cursor::new(bytes)).into_dimensions().ok()`).

`src/lib.rs`: `pub mod decode; pub mod scale; pub mod assets;` (the last is empty until W6-03).

Tests: build a 4×3 `Luma<u8>` in memory, encode it as PNG, decode it and check the dims and that the PNG is 4×3 greyscale; encode the same as JPEG (quality 90) and TIFF; a text file gives the unsupported message; a 12 001 px wide image built in memory is refused; `mm_per_px_from(100, 200.0) == 12700`, `(50, 300.0) == 4233`.
