Files: `v2/crates/cli/src/main.rs`; new test `v2/crates/cli/tests/pipe.rs`.

Problem found by the audit: `plan solve --json FILE | head -c 600` prints a Rust panic (`failed printing to stdout: Broken pipe`).

Do: replace every `println!`/`print!` to stdout in main.rs by a helper
```rust
/// Write a line to stdout. A closed pipe ends the program quietly with exit 0.
fn out(text: &str) {
    use std::io::Write;
    let mut stdout = std::io::stdout().lock();
    if let Err(e) = writeln!(stdout, "{text}") {
        if e.kind() == std::io::ErrorKind::BrokenPipe {
            std::process::exit(0);
        }
    }
}
```
(use `write!` in the same way where the old code used `print!`). Output text must not change: the snapshot tests stay as they are. `eprintln!` stays.

Test (tests/pipe.rs): start the built binary (`env!("CARGO_BIN_EXE_plan")`) with `solve --json ../../fixtures/lgh154-a.plan` (path relative to the crate, as the other CLI tests do), `stdout(Stdio::piped())`, `stderr(Stdio::piped())`; drop the child's stdout handle at once; wait. Assert the collected stderr does not contain `panicked`.

Done when: the test passes, the snapshots are unchanged, and `cd v2 && cargo fmt --check && cargo clippy -q -- -D warnings && cargo test -q` is green.
