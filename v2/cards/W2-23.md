Files: `v2/crates/server/src/lib.rs`; `v2/crates/core/src/diagnostics.rs` (new `Code::E022`, Error, template `View "{view}" is not available yet; use "plan" or "labels".`, wording test).

Arguments (schema fixed by the spec; all six views are accepted, two are implemented in week 2):

```rust
#[derive(Debug, Default, serde::Deserialize, schemars::JsonSchema)]
#[serde(rename_all = "lowercase")]
pub enum RenderView { Plan, #[default] Labels, Conflicts, Missing, Diff, Overlay }

#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
#[serde(untagged)]
pub enum RegionArg {
    /// Crop around one element: a room name, or a wall or opening id.
    Id { id: String },
    /// Crop to [x, y, w, h] in mm (x east, y south).
    Rect { rect_mm: [i64; 4] },
}

#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
pub struct RenderArgs {
    /// The plan: a file name under the server's root, without `.plan`.
    pub plan_id: String,
    /// labels (default): every room, wall and opening labelled with its id; plan: room names only.
    #[serde(default)] pub view: RenderView,
    /// Optional crop. Leave out for the whole plan.
    #[serde(default)] pub region: Option<RegionArg>,
    /// Image token budget, at most 4784. Default 1600.
    #[serde(default = "default_tokens")] pub max_tokens: u32,
}
fn default_tokens() -> u32 { plan_render::viewport::DEFAULT_TOKENS }
```

Tool: `#[tool(name = "render", description = RENDER_DESCRIPTION, annotations(read_only_hint = true))]`, `RENDER_DESCRIPTION = "Draw a plan as a PNG sized for you, with ids on every element. Use it to judge the layout, not to measure: numbers come from get and check. Crop with region (an id or a mm rectangle) to see detail."`

Flow:

```
view Conflicts|Missing|Diff|Overlay -> tool error [E022 with view name in lower case]
text = store.load(plan_id)?;  r = plan_core::load(&text) or tool error (its diagnostics)
resolved = r.resolved or tool error with the Error diagnostics of r
opts = RenderOptions { view: Plan|Labels, region: map RegionArg -> Region, max_tokens }
rendered = plan_render::render(&resolved, &opts) or tool error [d]      # E011 for an unknown id
bytes = plan_render::png(&rendered) or tool error [d]                   # E012
meta = {"plan_id", "view", "mm_per_px", "origin_mm", "size_px", "tokens",
        "labels": [{"id", "center_px"} for each rendered label]}
result = CallToolResult::success(vec![
    ContentBlock::image(base64 STANDARD encode of bytes, "image/png"),
    ContentBlock::text(meta.to_string()),
]); result.structured_content = Some(meta)
```

(`use base64::Engine; base64::engine::general_purpose::STANDARD.encode(&bytes)`; `ContentBlock` is `rmcp::model::ContentBlock`; this pattern was compiled by the spec owner.)
